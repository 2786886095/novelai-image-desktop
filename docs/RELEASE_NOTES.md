## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.5.0.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.5.0.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.5.0-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.5.0.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.5.0.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.5.0 更新内容

- **修复三套 NovelAI 个人法典切换看似无效的问题**：共同前言与重复说明不再混入搜索结果，切换后会直接显示各法典的真实独立内容。
- 作者、版本、使用说明与 NAI 测试环境统一整理为顶部“法典说明”，不再出现“复制提示词”；新增“访问原网站”直达入口。
- 离线法典数据重新整理为 14,541 条有效提示词，并对三套法典间的完全相同条目去重；旧缓存也会在界面层自动兼容。
- **随机画师串抽卡加入完整 NovelAI 生成参数（全端）**：支持模型、图片尺寸、自定义宽高、步数、CFG/Rescale、采样器、噪声计划、负面预设、负面提示词、质量词、Variety+ 与旧模型 SMEA。
- 抽卡参数首次继承生成页，可独立修改、持久化或随时从生成页重新同步；同组 A/B 对照严格使用相同内容、Seed 与参数。
- “应用到生成”现在会同时应用画师串、内容提示词与当前抽卡参数。
- 修复结果/收藏夹切换后保留中段滚动位置、顶部参数被遮挡的问题；切换视图会稳定返回顶部。
- 修复移动端折叠面板与页面滚动状态键冲突的问题，并新增手机竖屏、手机横屏、平板横屏及滚动回归测试。

### 使用与资源说明

- 法典内容来自 `nai4.top` 的公开法典页面；原页面声明为无偿免费分享，应用保留来源链接且不修改原提示词正文。
- 成人法典默认不会取代常规法典的初始视图，用户可在法典标签中主动选择。
- 所有 NovelAI 生图请求仍由用户自己的 Token 发起，实际 Anlas 规则与服务限制以 NovelAI 官方返回为准。
