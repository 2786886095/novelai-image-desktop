## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.7.0.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.7.0.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.7.0-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.7.0.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.7.0.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.7.0 更新内容

- 全面重做“参考图快捷预设”界面：桌面端采用创建区与本机预设库双栏布局，手机和平板改为单一稳定滚动区域与自适应卡片布局。
- 新增预设分组管理：可以创建分组、将新预设直接保存到当前分组，并把已有氛围迁移或精准参考预设移动到任意分组。
- 预设卡片集中展示完整图片、类型、主要强度参数、所属分组及应用、导出、删除操作；图片保持完整比例，不再强制裁切主体。
- 补齐简体中文、繁体中文、英语、日语和韩语界面文本，并完成桌面明暗主题及 Android/iOS 手机、横屏和平板共 46 张离屏截图复验。
