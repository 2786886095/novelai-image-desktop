## Latest — 图库移动原图与桌面 MCP 扩展

[下载当前版本](https://github.com/2786886095/novelai-image-desktop/releases/latest) · [当前源码](https://github.com/2786886095/novelai-image-desktop/tree/main) · [桌面 MCP 工具清单](https://github.com/2786886095/novelai-image-desktop/blob/main/docs/MCP_GALLERY_AND_PROMPTS.md)

- Windows 画风迭代的本机 GPU 实测未验收；不计为通过。
