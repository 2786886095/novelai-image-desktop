# 发行说明

## Latest — 自定义提示词工具栏、Windows 系统托盘与 Android 备份救援

[下载当前版本](https://github.com/2786886095/novelai-image-desktop/releases/latest) · [当前源码](https://github.com/2786886095/novelai-image-desktop/tree/main)

- 桌面普通与角色提示词共用自定义工具栏布局。主栏最多放 5 个可配置工具；满栏时可用「更多」中的工具换位，撤销、重做和「更多」不占名额。
- 将「还原」统一标注为「翻译还原」，保留恢复翻译前原文的功能。
- Windows 点击关闭窗口时，应用内确认框会跟随软件主题。可选择退出或最小化到系统托盘，并可勾选「不再询问」。托盘可恢复主窗口，也可完全退出。
- 「设置 → 外观 → 关闭窗口时」可重新选择每次询问、最小化到托盘或退出。其他平台不改变关闭行为。
- Android、iOS：修复画师抽卡页面重开后，滚动位置与高级选项的展开状态冲突。
- Android：手动导出或立即完整备份遇到可捕获的内存不足时，提供加密分段救援。救援包只包含旧版偏好文件，不包含原图或独立工作区，也不是常规备份，不能在原导入入口使用；原数据不改写。
- iOS 如提供未签名 IPA，需自行签名，不能直接安装到普通 iPhone；不是 App Store 或 TestFlight 发行。下载及验收范围以正式发行说明为准。

### 验收范围

- Android 分段救援已用约 170 MiB 的模拟旧偏好数据验证加密、完整性与解包。报告故障的实体手机尚未完成覆盖安装与导出实测。
- Windows 画风迭代的本机 GPU 实测未验收：未运行模型安装与恢复、运行生命周期、搜索评分和选中结果生成。此项不计为通过。
