## Langbai NovelAI Studio 2.4.7

### v2.4.7 更新内容
- 账号管理保留官方 API Token、官方邮箱密码、独立中转 Token 三种方式；验证成功后保存，按接口地址与 Token 去重，状态条统一绿色通过／红色失败和内嵌详情。
- 恢复账号独立的 Anlas 余额刷新与失败缓存；默认自动跟随系统代理，保留用户主动保存的代理设置。
- NovelAI 模型中转兼容原生与 New API/OpenAI Images 封装；保留流式预览，仅在明确不支持时按请求回退，不自动重试已开始的收费生成。
- 智能体问题卡支持推荐选项、点击确认和上下题导航；保存智能体设置，新对话继承已有选择。
- 「使用预设」更名为「使用酒馆」：控制创作资源预设是否传给助手。未保存选项时默认全自动、网页查询、使用酒馆开启；已保存选择不被覆盖。
- 补齐 Tag/MCP 工具自动发现与多工具配置、归档对话删除与文件路径入口；统一预览交互，恢复主画布滚轮缩放，修复回到最新、滚动跟随、浮层和作品页闪动。
- 提示词优化、自定义、反推和转换以已保存的混合模板为基准，支持派生纯 Tag / 自然语言模式，保留可见事实与模板要求。
- Windows、Android、iOS 共用功能源码同步。本次只提供 Windows x64 安装版与便携版。

### 下载与验证范围
- 安装版：`Langbai-NovelAI-Studio-Setup-2.4.7.exe`。
- 便携版：`Langbai-NovelAI-Studio-2.4.7.exe`。
- 发布前门槛：桌面类型检查与回归、Flutter 共用源码分析与回归、Windows 原生依赖及启动、实际 NSIS 解码、干净安装与旧版升级、隔离账号数据保留、按需组件启动／离线复用。
- 提供 `latest.yml` 自动更新元数据及 `verification.json` 制品摘要；公开附件应与验证过的哈希一致。
- 本轮不发布 macOS、Linux、Android 或 iOS 安装包，也不将共用源码测试等同于移动实机或苹果签名验收。兼容实现不等于每个第三方站点、Token 和收费模型都已实号验收；费用和权限以服务端为准。
