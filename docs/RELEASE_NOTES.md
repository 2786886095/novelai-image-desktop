## Langbai NovelAI Studio 2.4.4

### v2.4.4 更新内容

### 桌面酒馆 Agent：插件检查与更新
- 新增插件自动检查与更新，默认开启；插件区域默认折叠，折叠时仍显示状态。
- Agent 运行中先检查并等待空闲，不强制中断对话；停止后重新检查再应用更新。
- 根据当前运行环境选择兼容的插件版本；没有兼容版本或检查失败时明确提示，不自动禁用插件或强行放行不兼容版本。
- 更新前保留备份，在隔离环境检查候选组件；失败保留原组件和用户资料。
- 适配组件与官方 Harness 分别检查更新；下载沿用软件更新代理配置。

### 桌面生图与界面
- 生图配置统一为 NovelAI 官方 / NovelAI 协议兼容中转，沿用现有 Token 与图片接口，移除独立 OpenAI Images 生图入口。
- 明确非官方接口发送 Token 与鉴权失败后官方重试的区别；前者默认开启，后者默认关闭，已有选择保留。
- 升级反推、转换、提示词优化和提示词助手模板；移除 AI 故事拆分分镜入口，漫画工具保留逐行 Tag / JSON / CSV 导入。
- 新增本地与在线图片收藏管理、预览收藏入口及顶栏排列；调整文字层次、按钮、文件选择与交互动画。
- 修复参考图全屏预览层级及预览边框问题，精简风格选择器中的排序和管理入口。

### 移动端与下载
- 同步 Android / iOS 版本 2.4.4，构建号 163；包含画师串抽卡页面、响应式布局和交互修复。
- 改进模型下载与网络错误反馈；Android Agent 运行资源继续按需下载，不内嵌整个运行环境到 APK。
- 桌面 Agent 独立组件仍按需安装；Android 运行资源单独发布，已保存的对话与配置不因升级被清空。

### 下载与平台
- Windows x64：`Langbai-NovelAI-Studio-Setup-2.4.4.exe`（安装版）、`Langbai-NovelAI-Studio-2.4.4.exe`（便携版）。
- macOS：通用 DMG / ZIP，未签名；Linux x64：AppImage。
- Android：`app-release.apk`；iOS：`novelai-mobile-unsigned.ipa`，需自行签名或侧载。
- 发布流程检查桌面打包、Windows 安装升级、Agent 启动、macOS 双架构、移动构建及 Android 签名连续性；自动化结果不等同于实体手机验收。
