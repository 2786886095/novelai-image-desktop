## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.5.4.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.5.4.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.5.4-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.5.4.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.5.4.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.5.4 更新内容

- 漫画生成器新增“统一尺寸 / 逐分镜尺寸”模式；逐镜尺寸可按顺序一行一个导入，并严格限制为软件支持的 NovelAI 尺寸。
- 漫画生成器可上传一组全局精准参考图，每个分镜可独立选择参考图，并单独调整参考类型、强度与保真度。
- 精准参考图会复制到项目资源目录，不依赖原始图片位置；导出的项目 JSON 不包含本机图片数据或路径，跨设备导入后需重新选择。
- 随机画师串抽卡修正“复制画师串”和“复制完整提示词”内容相同的问题；完整提示词按“画师串 + 随机风格/光影词 + 固定附加词 + 基础提示词”组成。
- 复制画师串会自动补齐末尾英文逗号，并加入按钮状态和消息提示，避免无法判断是否复制成功。
- 新增已有画师串权重微调：保持画师名称与顺序不变，只在指定范围内随机调整权重并生成候选图。
- 上述漫画与画师串功能已同步到桌面端、Android 与 iOS，并补齐简体中文、繁体中文、英语、日语和韩语界面文字。

### 使用与资源说明

- 法典内容来自 `nai4.top` 的公开法典页面；原页面声明为无偿免费分享，应用保留来源链接且不修改原提示词正文。
- 成人法典默认不会取代常规法典的初始视图，用户可在法典标签中主动选择。
- 所有 NovelAI 生图请求仍由用户自己的 Token 发起，实际 Anlas 规则与服务限制以 NovelAI 官方返回为准。
