### v2.2.3 更新内容
- 在线画廊、AITag、在线参考库与本机参考预设统一为明确分页：支持每页数量、总页数、数字跳页，并在下一页准备完成前保留当前内容。
- 画师排行榜改为服务端分页，覆盖 Danbooru 全部有效画师标签；桌面端与移动端均可搜索、选择每页画师数量、查看总数并直接跳页。
- 画师代表作品默认展示 12 张并可继续翻页，双击进入完整预览，也可从预览前往原作品页面；画廊图片按原始宽高比自适应显示。
- 全应用原生下拉框迁移为统一选择组件，补齐键盘 Tab/Escape、首字母跳转、焦点恢复、无障碍字段名和超长菜单滚动隔离，并修复弹层跑到左上角的问题。
- 扩充简体中文、繁体中文、英语、日语和韩语覆盖范围，重点补齐酒馆 AI、生成、后期、参考预设和移动端界面；NovelAI Token 保存后可通过眼睛按钮查看。
- 提示词翻译新增 OpenAI 兼容 AI 翻译，可配置 API 地址、密钥并自动检测模型；原有 Google、百度翻译继续保留。
- 重构桌面端启动和页签保活：移除整包 WeUI、缩短启动关键路径、统一字体与应用内动效开关；修复工作台离场时生成图在其他页签短暂残留的问题。
- Flutter 移动端补齐页面转场、主题和间距令牌、分页预设与画师排行，同时加入多语言布局及对比度回归测试。
- 加强 AITag、在线图库、历史文件修复、异常边界与错误提示，失败加载可重试且不再清空当前页面。

> v2.2.3 包含此前版本的全部功能与修复，建议桌面端和移动端用户更新。
