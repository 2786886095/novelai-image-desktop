## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.9.7.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.9.7.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.9.7-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |

| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.9.7 更新内容
- 桌面端与 Android/iOS 生图尺寸支持完整输入后再校准：失焦或按 Enter 时才取最接近的 64 倍数，不再输入一位就跳值；支持官方小图、标准、大图和壁纸预设，并遵守 NovelAI `3,145,728` 总像素上限。
- 图生图默认按每张原图自适应到最接近的有效 64 倍数尺寸，也可切换为自定义输出尺寸；批量图生图同步支持“逐图自适应 / 统一自定义”，导入、编辑与结果卡会显示“原图 → 输出”尺寸。
- 新增 NovelAI 官方风格的质量词：`标准（Standard）`、V5 专用 `轻量（Light）`、`关闭（None）`，默认“标准”；采用与现有界面融合的柔和胶囊式三段选择，中文界面以中文名称和说明为主，生成页、漫画生成器、批量图生图与随机画师串抽卡均可设置。
- 新增 V5“透明背景”开关，默认关闭；启用后追加透明背景提示并请求 Straight Alpha 透明通道，生成页、漫画生成器、批量图生图与随机画师串抽卡均已覆盖，导入 NovelAI 元数据时也会恢复相关状态。
- 随机画师串抽卡升级为 V5 默认范围：每串默认抽取 3～7 名画师，画师权重默认 `0.2～1.2`；可选系列风格 Tag 默认 0～2 个、权重 `0.15～0.8`，Seed、数量与全部范围均可调整并可一键恢复默认。
- 工具板块新增“V4.5 画师串修复器”和“输入画师串抽卡”：自动识别画师、质量词和其他 Tag，清理异常分隔符并规范为 V5 数值权重格式；可生成多个候选、批量生图和收藏。随机抽卡、修复器与输入串抽卡分别使用独立收藏库。
- 局部重绘改用贴近 NovelAI 官方编辑器的 8×8 像素格蒙版流程，默认圆形并保留棱角分明的方形画笔；加入精确尺寸输入、滑杆、连续斜线绘制、橡皮擦、遮罩预览和快捷键，重绘输出尺寸始终跟随原图。
- 角色提示词支持独立折叠和直观的位置拖动；移动端拖动位置时会锁定页面滚动，避免整个界面随手势滑动。
- 生成队列改为先即时入队、后台完成报价与参数准备，桌面端工具按需加载且大型候选列表减少无效渲染，降低打开工具及连续加入队列时的卡顿感。
- 桌面端与移动端“关于我们”加入 NovelAI 交流群 **921985070**；GitHub README 同步加入群二维码和群号。
- 新控件全部沿用现有主题色、圆角、分段按钮、表单和卡片体系，避免与原界面产生割裂。
