# 更新记录

## Latest · 五平台日式漫画与模板库

- 桌面、Android、iOS均加入日式漫画生成器、图片／漫画转换目标、AI推荐页数与手动页数。整页及单分镜统一一行一页，1–30页；每批最多4整页／8单格，显式续批、确认导入，不自动生图或重试收费请求。
- 六份图片新版技能原稿、日式整页v4.1及单分镜v1.0完整接入；内置只读，支持命名另存、TXT/MD/JSON导入、自定义编辑和JSON导出。旧版与自定义原文保留；版本由用户显式选用，不静默升级。
- 手机与桌面模板库均接入备份恢复；项目、队列及转换／漫画草稿独立保存。损坏文件保留并阻止请求，不默默回退内置；取消只归属本请求，过期配置／凭据或脏编辑不覆盖，截断回复保留原文且不自动重发。
- 修复模板库右上操作受弹窗关闭按钮30×30样式误命中，按内容宽度换行整颗按钮。模型、画风、负面与收费配置不由模板文本自动改变。
- 修复移动端本地 MCP 服务启停期间的地址读取竞态；服务未就绪或正在停止时不显示／复制连接信息，过期的复制与审批控件不会读取旧连接或重复执行操作。已有鉴权、人工审批、预算和不重放约束保持不变。
- 正式发行门扩大到五平台：195个声明单元、187个必需单元；本地Agent组件和画风自动迭代仍仅Windows，其他平台8格为not-supported而非通过。追加10项漫画／模板原生场景并守住原有122项；具体实测与同源提交见本次Latest附件，不继承旧版本的实测结论。
- 本次Linux验收与支持基线明确为Ubuntu 24.04 LTS（x86_64），桌面构建及原生验收均记录实际系统、架构、glibc和同源提交；仍须通过原有完整功能、原生图像及最终打包运行门，不以runner标签或WSL检查替代。Ubuntu 26.04已观察到Sharp／Electron图像运行时卡住，当前不支持；其他发行版尚未验收。Ubuntu 24.04的实际通过情况以本次同源Latest证据为准，不表示Ubuntu 26.04问题已修复。
- iOS仅提供未签名IPA，须自行签名，不能直接安装普通iPhone，不是App Store/TestFlight版本。Windows/macOS代码签名、公证、升级和自动更新能力以实际制品及Latest说明为准；回环合成服务验收不证明真实模型画质或实际扣费。
