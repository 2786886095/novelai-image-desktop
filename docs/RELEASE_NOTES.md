## Langbai NovelAI Studio 2.3.6

### v2.3.6 更新内容

#### 局部重绘恢复自选输出尺寸（电脑端 / 手机端）
- 恢复与常规生图一致的尺寸预设与手动宽高输入，不再强制沿用原图大小。
- 原图和蒙版同步缩放，请求、合成结果及费用估算按所选输出尺寸处理。例如可将 1024×2048 原图重绘输出为 704×1408。
- 保留原图坐标下的蒙版编辑和未涂抹区域的合成逻辑，不改写原始图片文件。
- 所选尺寸仍需符合重绘接口的限制；具体 Anlas 消耗取决于模型、账号及生成参数，不承诺免费。

#### 历史图片分组持久化修复
- 修复电脑端图片手动归类后，刷新或重启又恢复未分组、原分组的问题。
- 修复换组、取消分组及分组改名/删除被历史扫描覆盖的问题。
- 保留图片在文件管理器中真正移动后的路径恢复能力。
- 旧版本已经丢失的分组关系需要重新设置一次；手机端新增分组保存和重载回归测试，未复现并宣称修复同一覆盖问题。

### 升级与验证
- 更新后请完全退出旧版本再重新打开；原有风格管理、Quick Tag Cloud 单向导入等功能继续保留。
- 电脑端与手机端版本统一为 2.3.6，Android versionCode 为 157。
- 本地桌面 1093 项测试通过，手机端 597 项测试通过，各跳过 1 项；类型检查、Flutter 分析和桌面构建通过。
- 使用隔离数据验证了 Electron 实际重启后的分组保留，以及原有尺寸选择界面；没有消耗用户 Anlas。安卓未进行真机验证。
- 发布门禁包含各端测试与构建、桌面原生启动与图片编解码检查（含 Intel Mac）、Android 签名延续与版本递增、更新安装包哈希核对。
