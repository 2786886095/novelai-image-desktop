## Langbai NovelAI Studio 2.1.0

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-2.1.0.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-2.1.0.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-2.1.0-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-2.1.0.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-2.1.0.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v2.1.0 更新内容
- 修复流式与非流式生图完成瞬间中间图片闪回、左右区域跳动，以及图片已采样完成但最终图偶发丢失的问题；桌面、Android 与 iOS 会等待本地成图解码完成后再切换完成状态。
- 修复“从历史与分组选择”偶发无法打开、原数据页面空白，以及旧异步读取覆盖新选择的问题；补齐对象 URL 与监听器生命周期清理，降低长期使用卡顿和内存累积。
- 新增正面提示词预设：可保存当前或手动输入的正面提示词、自定义名称、导入最多三张参考图并悬停/放大预览；生成、批量工具、V4.5 画师串修复器与随机画师串抽卡均可直接替换当前正面提示词。
- 正面提示词预设、画师串与可合并数据在备份导入时采用合并策略；同名项目自动按“（1）”递增，API 与基础配置仍需用户确认后覆盖。
- 完善随机画师串抽卡：支持自定义 Tag、每串必加并随机权重、每串加入或随机加入两种模式、分类搜索式画风 Tag 库，以及游戏/动漫风格 Tag；修正移动端布局与预览。
- 完善批量图生图，可逐行指定与图片对应的尺寸；优化画风 Tag 库折叠、分页定位、参考图预览和多语言含义显示。
- 完善跨端备份：可自选备份路径，Android/iOS 支持从系统分享直接导入 `.naisbackup`；图片、历史、预设与画师串尽可能合并，数据库覆盖前必须取得用户同意。
- 优化资源数据库下载与维护：显示下载进度，支持暂停/恢复、校验与失败修复；修正 Gitee 重复附件元数据选择。
- 升级并锁定存在安全公告的依赖；减少重复事件监听、过期 FileReader 回调和未释放图片 URL。完整桌面与移动测试、Android 构建及真实资源库下载校验均已通过。
