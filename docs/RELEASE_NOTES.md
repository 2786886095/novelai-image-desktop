# v2.7.2 — 桌面网页导入客户端、手机入口与数字输入修复

## 更新内容

- 桌面新增`langbai-novelai://relay/import?code=...`一次性中转账号导入：严格验证链接、固定JSON兑换接口，原始链接／码／密钥不写入应用日志或剪贴板；默认名称递增、同址同密钥复用、不覆盖原账号，沿用系统加密凭据库。
- 空闲时自动选中并尝试刷新积分；正在生成、后台任务或账号验证持有凭据租约时，仅保存并提示“已添加，任务结束后可切换”。主进程落实保护，不依赖前端禁用。启动前后事件排队和跨进程摘要记录防止重复兑换，失败要求回网站获取新码。
- Windows／Linux冷启动与second-instance、macOS早期open-url接收路径及安装协议声明已实现；Windows便携版注册真实外层EXE而非临时解压路径。需正常退出旧版，将软件放到固定位置并首次启动注册。Mac/Linux系统关联未完成实机验收；[详细协议与使用要求](https://github.com/2786886095/novelai-image-desktop/blob/main/docs/WEB_RELAY_IMPORT.md)。
- 手机端设置页和账户管理页顶部加入内置网站LN Logo的推荐入口，点击在外部浏览器打开`https://nai.langbai.cc`，不更改API配置、不附带密钥。手机推荐入口不包含本次桌面深链账号导入。
- 修正Android种子／批量数量输入弹层读取已卸载context的问题，保留既有功能和用户数据；红米K70真机仍需用户复核。

## 已知限制：网站一键导入尚未端到端验证通过

- 2026-11-03按客户端格式发送的虚构无效码请求返回`HTTP403 ORIGIN_REJECTED`；携带网站来源的单独诊断返回`HTTP403 Cloudflare1010 browser_signature_banned`。公开前端包检查未发现一键导入或唤起协议引用；这不证明所有登录页面／后端实现都不存在。
- 没有使用真实导入码、真实密钥或登录态完成导入，**不能宣称网站现在已可一键导入**。网站方仍需确认按钮、签发与兑换接口部署，并检查来源验证和Cloudflare规则。客户端遇到接口未就绪／失败将明确提示，不伪造成功、不重试旧码。
