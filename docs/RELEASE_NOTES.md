## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-2.0.0.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-2.0.0.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-2.0.0-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-2.0.0.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-2.0.0.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v2.0.0 更新内容
- 修复 API 源返回 Cloudflare 502/503/504 网页时整页 HTML 覆盖软件的问题：错误现在会转换为简短提示，提示框可手动关闭且不会撑开状态栏。
- 修复异常 IPC 请求可能遗留“正在生成”状态、导致生成按钮消失且只能重启的问题；文生图、图生图、局部重绘、超分与后期处理均会可靠解除生成锁。
- 修复生成期间删除历史记录后，过期图片元数据可能覆盖当前提示词的问题；生成参数在请求开始时固定快照，历史图片异步读取、删除和新生成之间互不串改。
- 图片反推新增 V4.5 / V5 模板选择；V5 的 Danbooru、自然语言和混合模板继续优化为更短、更明确的执行规则，混合模式保持约 80% Tag + 20% 自然语言并附中文释义。
- 完善网络、游戏和动漫角色的“角色名版 / 特征版”双结果：转换与反推均会检查双版本完整性，缺失时自动补全，并接入个人法典增强与二次规则修复。
- 统一随机画师串、输入画师串与 V4.5 修复候选的结果卡片和操作键位；双击或预览按钮均可打开原比例大图，横图、竖图按实际宽高展示，不再强制裁成方形。
- 桌面端与移动端同步模板版本、已知角色模式和个人法典规则；清空反推或转换记录前增加二次确认，避免误删。
- 新增 Cloudflare HTML 净化、各付费图像功能异常恢复、历史删除与提示词快照竞争等回归测试。
