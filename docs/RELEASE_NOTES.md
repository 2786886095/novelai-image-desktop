# 更新记录

## Latest · 桌面控件与交互一致性改进

### 本轮修复范围

- 桌面共享按钮、输入、选择器、弹窗和间距沿用现有主题与尺寸契约，补齐键盘焦点、加载、禁用及减少动效状态；图片查看器、预览与画布等专用工具条保留自己的布局，不用全局原生控件重置覆盖它们。
- 历史栏及作品库的“恢复转换图片索引”改用共享按钮，修正同一动作在不同上下文中样式割裂的问题；不改变此前的安全索引重链、备份恢复边界或图片字节。
- 主工作台和漫画工具共九处文件选择入口改用既有共享组件，保留文件类型、多选、禁用、重置与原回调，补齐 Enter／空格操作；不把界面整理写成导入协议或生成行为变更。
- 修正账户弹窗标题双重内缩，统一普通账户输入及动作的尺寸、圆角、禁用和焦点样式。登录方式卡片保留最小高度与文案换行空间，不强制长文案卡片等高为最小值；不改账户数据、鉴权或请求流程。

### 五平台范围与证据

- 界面变化面向 Windows、macOS、Linux 桌面端。Android、iOS 本轮仅同步版本／构建元数据，不宣称已移植这套桌面界面。五平台发行附件必须从本轮源码重新构建，不能将旧二进制改名冒充。
- 沿用已经完成的桌面定向测试、固定共享控件浏览器探针及隔离视觉记录；视觉记录使用合成数据，账户布局修正前快照与修正后的定向复核分开标明，不能把旧截图当最新账户布局。它们不是全部嵌套分支或原生设备的完整验收。
- 本轮新构建、编译、制品来源与静态核验、签名连续性、上传和回读完成情况，以实际运行记录及 Latest 的 verification.json 为准；本说明不预填新构建、上传或发布成功。
