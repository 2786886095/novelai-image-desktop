# 发行说明

## Latest — 重绘蒙版选区

确认选区时，编辑器会清除框外已有蒙版。跨过边界涂画或擦除只影响框内，取消或扩大选区不会恢复已清除的笔迹。

- iOS IPA 未签名，普通 iPhone 需自行签名才能安装。
