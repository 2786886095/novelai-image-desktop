### v1.3.0 更新内容

这一版是一次全端深度审计后的修复合集，重点是任务取消/停止的可靠性、历史记录数据安全、以及几处安全加固。

**取消 / 停止相关：**
- 修复桌面端多个生成入口（文生图、图生图、重绘、超分、后期）共用同一个"取消"状态导致的问题：旧任务收尾时可能误清空新任务的取消信号，导致点"停止"没反应，新任务却仍在计费。
- 修复批量图生图切走标签页再切回来后，旧任务收不到停止信号、无法真正停止的问题。
- 修复漫画生成器正常跑完一批后离开页面，会误触发一次多余的全局取消。
- 修复移动端漫画/批量图生图离开页面后队列仍在后台运行、并可能在已销毁的页面上触发异常的问题；离开页面现在会真正停止队列。
- 修复移动端所有生成功能共用一个取消状态、并发时互相干扰的问题。
- 修复图生图/重绘/超分/后期这几个按钮快速双击可能触发两次请求的问题（此前只有文生图做了防护）。
- 修复生成成功保存后，如果余额刷新恰好失败，会把已经成功的结果误判为失败的问题（桌面端 + 移动端）。

**历史记录与数据安全：**
- 设置/历史记录文件改为原子写入并保留最近两份快照，崩溃或断电导致文件写坏时会自动从快照恢复，不再直接重置为空。
- 修复历史记录在超大素材库或移动/网络盘暂时离线时，可能被误判为"文件已删除"从而整批清空历史索引的问题；现在区分"确实找不到"和"暂时无法确认"，后者不会删除记录。
- 修复批量图生图导入项目文件时的一个安全隐患：精心构造的项目文件可以让程序把任意本地文件当作生成结果读取、并通过导出 ZIP 带出去；现已加上路径校验。

**安全加固：**
- Token 请求强制使用 HTTPS，避免代理环境下明文传输。
- 自定义生图 Endpoint 鉴权失败后，不再默认静默切换到官方地址重试（避免意外用官方账号计费），改为可选开关。
- MCP 的 SSE 传输加了同源校验，防止被恶意/被劫持的服务器把请求重定向到其他地址、带走密钥。
- 桌面端加了导航与新窗口拦截，降低未来出现问题时的影响面。

**桌面端启动：**
- 启动时如果某个非关键读取失败（比如历史记录、账号缓存），不再卡死在启动动画；只有设置读取失败才会显示错误并提供重试按钮。

**移动端：**
- Android 目标 SDK 升级到 35（Google Play 新版本要求）。
- 导入漫画/批量图生图项目文件时加了图片数量与大小上限，避免超大或异常项目文件导致内存溢出或启动崩溃。
- iOS 上长时间生成队列切到后台/锁屏可能被系统中断（iOS 没有和 Android 对等的后台保活能力），现在开始任务时会提示保持前台。
