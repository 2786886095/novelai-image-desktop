# 发行说明

## Latest — 桌面 MCP 图库分组、Tag 分类与迭代查询

[下载当前版本](https://github.com/2786886095/novelai-image-desktop/releases/latest) · [当前源码](https://github.com/2786886095/novelai-image-desktop/tree/main)

- Windows、macOS、Linux：MCP 可创建图库分组、批量移动作品。只改变图库归属，不移动原文件。
- Tag 分类读取图片内嵌的正面和角色提示词；先预览，再在 Studio 确认。缺少元数据或命中多个目标分组时跳过。
- 迭代查询按 Tag 相似度至少 50% 查找并按生成时间排序；角色改变的相关结果单独显示。相似度不是实际重绘关系的证明。
- Android／iOS 仅同步版本，不包含这次桌面新增的图库 MCP 工具。
- iOS 附件为未签名 IPA，需自行签名，不能直接安装到普通 iPhone；不是 App Store 或 TestFlight 发行。
