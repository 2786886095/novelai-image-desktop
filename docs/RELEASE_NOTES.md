## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.7.2.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.7.2.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.7.2-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.7.2.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.7.2.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.7.2 更新内容

- 桌面端与移动端参考预设库新增在线角色精准参考目录，可按游戏、游戏内角色图/角色立绘分类和角色形态筛选，并优先使用 Gitee 中国大陆线路。
- 在线目录只下载每个角色与形态选定的最佳 NovelAI 精准参考图，显示文件大小和实时下载进度；下载后直接进入本机预设库并支持离线复用。
- 角色名、形态名、游戏名和分类名支持简体中文、繁体中文、英语、日语、韩语显示及跨语言搜索；切换软件语言后，本机已下载预设也会同步切换名称。
- 单分类游戏自动隐藏多余分类选择；新增目录内存与 HTTP 缓存、Gitee/GitHub 自动回退、分页加载和缩略图快速预览，减少反复读取与首屏卡顿。
- 桌面端在线目录改用 WeUI 搜索、选择器、按钮、进度和状态组件，并使用 GSAP 提供面板、卡片、筛选及预览动效；同时支持系统“减少动态效果”设置。
- 优化桌面深浅色主题、窄窗口、手机纵屏和横屏/平板布局，修复搜索框空白或重复图标、预览遮罩透明、按钮漂移及文字溢出问题。
- 移动端参考预设库升级为独立入口，支持创建分组、搜索、预览、删除确认、导入导出及从在线目录下载；Flutter 端使用原生触控组件与等效动画。
