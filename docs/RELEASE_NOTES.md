# 发行说明

## Latest — 桌面灵感胶囊

分类精选与全库标签保留各自的目录。全库可按眼睛、发型等小类筛选，标签卡显示使用量。两种目录都支持平滑展开与收起；开启减少动态效果时立即切换。

## v3.0.6 — 手机提示词工具与角色预设

手机角色卡可从灵感胶囊选词，批量填充时默认保留未列出的角色。可命名、保存和应用角色组合；旧组合也可通过角色名、正面词或负面词找到。

- 移除末尾多余角色需单独确认；更改预览后需重新确认。
- 单角色正面预设只写入选中的角色正面词，不覆盖负面词或位置。
- OpenCode Go：转换、带图反推和智能体按任务或对话复用会话头，不向其他 API 发送。
- iOS IPA 未签名，普通 iPhone 需自行签名才能安装。
