### 修复范围

- **#76 · PNG 角色提示词导入**：有效 NovelAI 生成 Comment 的结构化数据优先于共存的 A1111／SD `parameters` 摘要，恢复独立角色正负提示词与坐标，原始摘要仍保留可见。桌面与移动端同步；这证明已复现的双元数据问题类别，不声称拿到了报告者未提供的原始 PNG。
- **#77 · PNG／WebP 保存选择**：保存格式与元数据保留开关独立，默认 PNG、不改旧文件。选择 WebP 时，对预处理后的 8 位像素作真实无损编码并按最终字节命名，保留透明 RGB；元数据开启时保留生成信息并写入可读 EXIF，关闭时先清理文本、EXIF 与像素载荷。高位深 PNG 保留 PNG 避免降精度；编码不可用时保留已获取结果，不重新发送付费请求。体积取决于内容，不保证小于 PNG。
- **#78 · `skip_cfg_below_sigma`**：移动端加入受限数值白名单与原模型绑定的元数据重放，明确保留 0；缺失值不补默认，不把任意 Comment 透传。桌面原有按模型绑定的重放继续保留，并随分类修复避免被 SD 摘要路径丢弃。
- **#79 · 历史日期异步竞态**：已用确定性回归复现“旧刷新响应晚到，覆盖新生成日期及记录”的问题，桌面加入刷新过期结果保护；移动端确认既有存储竞态保护并补做对照；本地午夜与月末边界也纳入检查。报告者具体缺少 10-31 的原始状态仍无法确认，不声称所有日期问题都是 UTC 或同一根因。
