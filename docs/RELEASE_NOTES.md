## Langbai NovelAI Studio 2.4.8

### v2.4.8 更新内容
- #35：智能体模型设置支持获取服务商模型列表、搜索并选择添加模型，也可手动添加。模型按服务商独立保存，每个模型分别保存上下文长度、思考强度与相关能力；对话选择器只显示已添加模型。
- #36：智能体回复期间可使用「+」继续添加文件；附件进入下一条消息的草稿，不修改已经发出的请求，也不丢失正在生成的回复。
- #37：智能体输入框支持选择文件、拖入文件、粘贴文件或图片；普通文本粘贴保留原有行为。附件采用托管副本，并检查类型、数量和大小，失败不遗留半成品。
- Windows、Android、iOS 的对应功能源码同步；修复严格 Flutter 分析诊断，不关闭规则或删减测试。
- 保留 v2.4.7 的账号验证、NovelAI 中转、Anlas 缓存、代理、使用酒馆及提示词模板等行为；本次不扩展为非 NovelAI 模型中转。

### 下载与验证范围
- 安装版：`Langbai-NovelAI-Studio-Setup-2.4.8.exe`。
- 便携版：`Langbai-NovelAI-Studio-2.4.8.exe`。
- 本次只发布 Windows x64 安装版与便携版，附带 `latest.yml` 自动更新元数据及 `verification.json` 验证摘要；不发布 macOS、Linux、Android 或 iOS 安装包。
- 正式发布必须通过桌面类型检查与回归、严格 Flutter 源码分析与回归、Windows 原生依赖与启动、实际 NSIS 解码、干净安装与旧版升级、隔离用户数据保留、按需组件启动与离线复用；公开制品哈希必须与已验证字节一致。
- Windows 安装包未配置代码签名，系统可能显示 SmartScreen 提示。共享源码、自动化测试及原生编译不等同于移动实机手势验收；也不表示每个第三方服务商或模型都已实号验证。
