### v2.2.8 更新内容

#### 酒馆画面编辑更简单
- 新增右侧「场景」页：角色、角色所穿服装和场景背景集中展示；输入一句修改要求即可提交，不必逐项设置归属。
- 高级 Tag、锁定与归属编辑默认折叠，已有约束继续保留。
- 修复「编辑画面」打开后只有描述、没有编辑入口：没有结构化数据的既有文字方案也提供修改输入框。
- 修改沿用当前确认／自动生成模式；保留原图片、历史方案和聊天框未发送草稿。历史方案只读，已生成的结构化方案可创建独立可编辑副本。

### 修复没有图片、也没有失败反馈
- 模型服务、提案解析、图片生成和通信失败提供明确反馈与重试入口。
- 生图服务返回空结果或不存在的文件不再被当作生成成功。
- 对有效既有方案说「重新生成」时直接复用方案，避免重复调用模型；自动模式直接生图，确认模式显示可操作的生成按钮。
- 主动发送后定位新消息及生成操作，同时保留用户浏览历史、展开内容时的滚动意图。

### 升级与数据
延续 v2.2.7 的酒馆工作区备份、迁移和校验保护；不会将用户图片、会话或密钥打进安装包。
若 v2.2.6 提示 `UPDATE_DATA_AT_RISK / LangbaiWorkspace`，请关闭旧版后手动运行本页安装包，不要删除原工作区。其他位于安装目录内的自定义输出或下载目录仍需先迁出，避免升级覆盖。

### 验证说明
桌面回归 946 条通过，两套 TypeScript 类型检查通过；针对酒馆失败反馈、文字方案编辑、结构化编辑、确认／自动模式等进行了 85 项隔离桌面联调。联调使用本地模拟模型和图片服务，不代表所有外部模型均已实测。
