## Langbai NovelAI Studio 2.3.1

### v2.3.1 更新内容

#### 图片与交互
- 修复粘贴或更换输入图片后，中间预览仍显示旧图的问题；生成完成后切换至新结果。
- 桌面端支持 Ctrl+C / Cmd+C 复制当前图片，保留文本选择和输入框的正常复制行为。
- 调整全局下拉菜单与折叠动画，补齐收回过程，缩短展开与收回时间。
- 移除图片区域多余的蓝紫色边框，调整角色编辑面板间距。
- 修复手机端图生图更换输入图片时，风格与正面提示词被图片元数据改写的问题。

#### 角色提示词
- 支持拖动角色卡片调整顺序，拖动时折叠、显示悬浮卡片与插入位置，结束后恢复展开状态。
- 调整顺序后可选择同步位置或保留原位置；优化画布中的角色位置拖动。
- 角色保存统一到正面预设，支持选择保存的角色。

#### 在线画廊
- 增加跨来源共用收藏库，红心收藏，支持筛选、搜索与多种排序方式。
- TAGs 增加名称排序；已收录的名称按界面语言显示，缺少可靠对应名称时保留原名，原始提示词标签保持不变。
- 软件更新与下载入口统一使用 GitHub。

### 安装包
- Windows 安装版 `Langbai-NovelAI-Studio-Setup-2.3.1.exe` 与便携版 `Langbai-NovelAI-Studio-2.3.1.exe`。
- macOS Universal DMG/ZIP、Linux AppImage。
- Android 稳定签名 APK；iOS IPA 未签名，需要自行签名。
