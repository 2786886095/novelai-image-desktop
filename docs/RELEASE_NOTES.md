## Langbai NovelAI Studio 2.3.4

### v2.3.4 更新内容

### 风格预设与图片操作
- **#20（电脑端）**：图片右键菜单新增「复制图片」，复制原图而非界面截图。
- **#21（电脑端 / 手机端）**：导入旧图时，若正面提示词开头与已保存的风格提示词精确匹配，会恢复到独立风格栏并关联已有预设。未匹配的内容保留原文；明确记录的风格字段优先。
- **#22（电脑端 / 手机端）**：「保存为风格预设」加入更清晰的参考图、大图预览与左右切换，可从大图直接保存当前对应的风格和图片。
- **#23（电脑端 / 手机端）**：每个风格预设的参考图上限从 3 张增加到 9 张，支持预览与切换，保存后重新打开仍保留。

### 交互修复
- 风格参考图和收藏风格的大图预览支持点击空白关闭；点击图片、缩放和拖动不会误关下层窗口。
- 大图预览工具栏上移 12 像素，与图片留出空隙。
- 采用 PR #25 的混合剪贴板修复：输入框粘贴同时含文字和图片的数据时优先文字。PR 中的画师比较与组合探索功能本次未合入。

### 启动反馈
- 增加启动进度窗口与失败提示，系统代理探测不再阻塞主窗口创建。
- **#24「有关程式开启」保持打开**：尚未复现反馈用户机器上的启动问题，本次不宣称已经解决。

### 安装包
- Windows x64 安装版 `Langbai-NovelAI-Studio-Setup-2.3.4.exe` 与便携版 `Langbai-NovelAI-Studio-2.3.4.exe`、macOS Universal DMG/ZIP、Linux x64 AppImage。
- Android 稳定签名 APK；iOS IPA 未签名，需要自行签名。
