# 发行说明

## Latest — 标签库安装与断点续传修复

- 已安装 11 月 15 日或 16 日版四语词库的用户无需卸载或清空数据。在「设置 → 离线 Tag 词库」选择原语言并点击「更新词库」即可；每种语言单独更新，下载及校验期间仍可使用原词库。基础 Danbooru 标签目录和相关标签数据库不受影响。
- Android 使用安装包内的 SQLite 打开基础 Danbooru 标签目录，修复下载到 44.6 MB 后因缺少 FTS5 而无法安装或搜索的问题。如果此前下载已完成且文件校验通过，更新后点击「继续」即可复用，不必手动清空数据。
- 桌面和手机在续传时核对服务器返回的起点、终点和总长度。遇到错误范围会保留原片段并尝试备用线路；基础目录、相关标签库以及简中、繁中、日语、韩语词库均受益。只有通过完整性校验才会安装新库。
- Windows 等桌面端下载标签时同时使用系统信任的根证书，仍严格校验 HTTPS。四语离线词典已更新至 2026-11-26，每种语言 510,583 条；同步更新 17 个分类索引。
- 手机下载四语词库遇到临时断流时自动从保留的字节续传，最多重试三次；仍离线时会提示进度已保留，旧词库保持可用。修复安卓随机画师串抽卡恢复空收藏夹时灰屏的问题。
- 标签库专项使用真实的 221,787 条标签验证安装与搜索，覆盖 Windows x64、Linux x64、Intel Mac、Apple Silicon Mac、Android 14 模拟器和 iOS 26.2 模拟器；不代表所有手机和系统版本都已实机测试。

Windows、macOS、Linux 和 Android 用户可从发行附件手动下载对应平台包。iOS IPA 未签名，普通 iPhone 需自行签名后安装。
