# 发行说明

## 桌面端：角色批量填充

- 感谢 Yuemil 提交 PR #93。经典和新版桌面界面的「生成 → 角色提示」底部均新增「批量填充」。
- 复制指令交给自己的 AI，或读取当前角色后修改。粘贴回复或导入 JSON/TXT，预览确认后才写入；角色组合可命名保存。关闭二级弹窗保留草稿，不改当前角色。
- MCP 可用 `prepare_character_group` 预览、`save_character_group` 新建角色组合；这两项操作不会发起付费生成。
