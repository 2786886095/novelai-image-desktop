## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.7.9.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.7.9.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.7.9-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.7.9.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.7.9.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.7.9 更新内容

- 随机画师串抽卡改为使用一套独立的 NovelAI 参数：首次使用软件初始默认值，可同步主生成页参数或一键恢复默认，不再被主页面临时修改意外影响。
- 抽卡结果与收藏会永久记录实际生成模型；收藏夹支持按 V5 Full、V5 Curated、V4.5 等模型筛选和分组，旧收藏会从历史图片模型信息兼容识别。
- 桌面端双击、移动端双击抽卡图片可打开大图预览；结果卡片明确显示生成模型与 A/B 风格词类型。
- 老用户的 V5 迁移公告升级：明确提示旧 V4/V4.5 画师串在 V5 下可能弱化、失效或改变，并重新向已关闭旧公告的用户展示一次。
- 统一提示词工具栏、Seed、批量数量和历史筛选控件的高度、图标与文字基线；历史原生长下拉改为应用内选择器，图片的移动分组/删除操作在桌面悬停时出现、触屏端始终可用。
- 图片删除和移动分组改为先更新界面、失败再回滚；历史文件扫描合并限频，减少删除图片和刷新列表时的卡顿。
- Gitee 安装包同步改为更小分片并延长上传窗口，继续作为中国大陆用户的软件内默认更新线路。
- 内置候选中 33/33 个标签已于 2026-08-22 验证为 Danbooru 当前有效、非废弃画师标签；这只证明标签状态，不代表 NovelAI V5 一定准确复现对应画风。
