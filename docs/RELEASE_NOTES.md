## Langbai NovelAI Studio 2.3.7

### v2.3.7 更新内容

### 酒馆 Agent（Windows x64）
- 新增独立 Harness 启动器，日志为主区域；Studio 适配组件与 Harness 官方版本分别检测。
- 每次进入酒馆页面检测更新；先校验兼容性，通过后由用户确认，再备份并安装，不直接安装未经适配的官方版本。
- 本次兼容组件 0.1.2 / Harness 0.1.7-rc.2。官方更新不等于已有兼容更新，自定义插件未获确认兼容时保留现状。
- 插件加载失败不再误报启动成功；修复旧版随附插件的已知兼容问题。自定义插件、配置、会话不随软件安装包覆盖。
- 提供备份位置、打开备份和恢复入口；升级失败保留旧组件与数据。退出正在运行的 Agent 使用软件内确认界面。
- 独立组件当前仅提供 Windows x64；macOS/Linux 保留现有酒馆界面，Android/iOS 保留原有移动酒馆。全平台安装包不等于全平台已具有本地 Harness 引擎。

### 画风、提示词与交互
- 新增本地画风筛选与评分流程，提供完整/轻量资产与 PyTorch 环境按需下载、大小、速度、进度和存放位置。
- 此流程仅开放 NAI 4.5 Full；完整版要求至少 8GB 显存，轻量版实际占用取决于设备。模型相似度不是图片还原百分比。
- 更新混合、Tag 与自然语言提示词模板；统一文件选择、滑块、图片预览与点击空白关闭行为。
- 生成完成提示音移到单独设置分类，可试听、调节音量和选择自定义音频；修复非主动操作时的复制提示。
- 修正超分尺寸请求和 MAX 结果处理；未知第三方中转接口仍可能存在差异。

### 数据与语言
- 更新桌面/移动跨端备份分类，识别新版 Agent 与画风实验室数据，显示恢复或保留待恢复的状态。
- 模型和运行环境不随数据备份迁移；换机后重新下载或绑定。移动端保存桌面专用数据但不执行桌面任务。
- 补齐简体中文、繁体中文、英语、日语、韩语界面与 README 语言入口；用户内容、路径和第三方原始诊断不翻译。

### 安装与发布范围
- Windows x64 安装版/便携版、macOS Universal DMG/ZIP、Linux x64 AppImage、Android APK、iOS 未签名 IPA。
- Android 版本 2.3.7，versionCode 158，沿用稳定签名。iOS 包需自行签名或侧载，不是 App Store 发行。
- Agent 组件单独发布为 agent-v0.1.2；程序升级与组件升级相互区分。
- 发布记录包含各平台构建、原生桌面启动检查、APK 签名延续与安装包摘要；不宣称所有第三方插件、未来官方版本或中转接口均已验证。

Windows 安装包：`Langbai-NovelAI-Studio-Setup-2.3.7.exe`；便携包：`Langbai-NovelAI-Studio-2.3.7.exe`。
