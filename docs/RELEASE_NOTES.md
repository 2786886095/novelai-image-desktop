### v1.4.5 更新内容

- **画风实验室：目标图片自动迭代（Windows）**：可从目标图或用户提供的基础提示词开始，以固定提示词、种子和生成参数批量试验画师串；本地 DINOv2 高精度模型为默认方案，也可切换轻量模型。
- 引入“无画师基线 = 0%、目标图 = 100%”的归一化相似度，达到目标阈值或用户手动停止才结束；长期停滞时自动扩大候选池并重组全部画师词与权重。
- 候选画师不再只做纯随机抽取：先依据公开 Danbooru 标签热度建立动态候选池，再借助公开代表图的本地缓存和视觉特征筛选与目标画风更接近的方向。标签帖子数只是热度先验，不等同于真实用户人数。
- **随机画师串抽卡（Windows、Android、iOS）**：每次抽卡都会重新组合画师标签并随机分配权重，可输入任意正整数生成本批数量；固定提示词、种子和参数，便于直接比较画风差异。
- 随机抽卡模式只使用画师名与权重，不下载代表图；支持可选的非画师词变异、收藏喜欢的组合、复制或一键应用画师串，并可刷新扩充动态画师池。
- 画风实验室图片使用专用分组和目录保存：`画风实验室-目标迭代`、`画风实验室-随机抽卡`，避免与普通生成结果混放。
- 移动端随机画师串页面针对竖屏手机、横屏手机与横屏平板重新适配，避免按钮、文字和卡片漂移或重叠。
- 漫画生成器工作区固定为不透明白色背景，深色主题下也保持稳定的漫画编辑视觉。

### 使用与资源说明

- 目标图自动迭代会在本机下载并缓存所选 DINOv2 模型；高精度模型更占内存和磁盘，轻量模型速度更快、资源占用更低。
- 随机抽卡数量不设产品层面的上限，但实际生成速度、内存占用和 NovelAI 请求稳定性仍取决于设备与网络，建议按设备能力分批生成。
- 所有 NovelAI 生图请求仍由用户自己的 Token 发起，实际 Anlas 规则与服务限制以 NovelAI 官方返回为准。
