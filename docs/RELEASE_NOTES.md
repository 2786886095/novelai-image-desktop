## Langbai NovelAI Studio 2.2.6

本版为电脑端更新。手机端保留 v2.2.5，本次不发布 Android / iOS 安装包。

| 系统 | 安装包 |
| --- | --- |
| Windows x64 便携版 | `Langbai-NovelAI-Studio-2.2.6.exe` |
| Windows x64 安装版 | `Langbai-NovelAI-Studio-Setup-2.2.6.exe` |
| macOS Intel / Apple 芯片通用 | `Langbai-NovelAI-Studio-2.2.6-universal.dmg` / `Langbai-NovelAI-Studio-2.2.6.zip` |
| Linux x64 | `Langbai-NovelAI-Studio-2.2.6.AppImage` |

macOS 仍未签名；Windows 便携版与安装版需要自备 NovelAI API Token。

### v2.2.6 更新内容
- 酒馆生图加入可编辑的结构化提示词：按角色、服装和物品组织内容，绑定表情、动作、穿着关系；支持固定、解除绑定、删除和撤销，避免多轮修改误删其他角色的 Tag。
- 修复自动模式和确认模式的生成衔接，使用右侧生图参数，空风格提示词不会继承生成页内容；完善失败重试、防重复点击和保存状态反馈。
- 改进折叠悬停、焦点与展开反馈，保留阅读锚点；复制操作明确显示进行中、成功或失败。
- 修复 AITag 接口响应兼容和读取失败处理；改进画师候选库加载、固定排行榜与全库随机抽样、选定数量同步。
- 原数据一键应用可选择参数，完善 NovelAI V5 元数据与角色参数恢复。
- 修复不同启动目录造成的密钥解密问题；解密失败保留原密文并提示，不再把密文当有效密钥发送。
- 模型空回复、输出截断或任务未完成时不再报假成功；保留已有方案与用量并支持重试。
- 加强更新数据保护。历史检查改为按目录缓存，约5,000条历史的安全路径实测从61秒降至约1.4秒，同时保留目录链接检查。
- 显式声明 sharp 图片编解码依赖，补齐干净安装与构建所需依赖。

### 更新前请注意
如果图片、下载目录或 `LangbaiWorkspace` 位于软件安装目录内，安装程序会停止更新以保护数据。请先导出酒馆工作区、把图片与备份复制到安装目录外并核对完整，修改保存路径，再将原目录移出安装目录后重试。此保护不会自动删除或静默搬走用户文件。
