# v2.7.3 — 在线画廊月份、手机固定布局与更新提醒修复

## 更新内容
- 桌面和手机在线画廊修复月份配置处理：支持原始与已规范化缓存数据；失败明确提示并允许重试，不再静默显示为仅更早作品。手机外层刷新通过信号更新，保留月份、关键词、页码与编辑内容。
- 手机固定顶部导航、设置推荐入口和搜索框；进入分类详情仍保留。修正漫画标题纵向裁切、四步导航溢出、加载条与模板标签贴合，以及按钮遮挡图片。较长导航标题提供完整Tooltip，减少动画选项仍有效。
- 图片解码失败有默认降级；当前路径失效显示明确说明并保留历史。并非删除文件、改路径或伪造图片加载成功。
- 启动检测到新版提供更新、浏览器下载、取消三个选择；同版展示后持久防重，下个版本可再次提醒。与V5迁移提示串行；生成、队列、漫画、批量重绘任务期间延后提醒或阻止安装。
- 保留既有账号、参数、工作流、模板和用户数据，不要求卸载或清空数据。
