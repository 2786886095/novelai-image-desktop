## Langbai NovelAI Studio 2.4.3

### v2.4.3 更新内容

### 目标画风自动迭代：两个模型独立管理
- 完整版 PE-G50 与轻量版 PE-L24 分别保存模型目录、Python 环境、下载位置和校验结果，模型切换入口始终显示。
- 切换版本不自动下载；按需下载对应资源，校验成功后才启用，失败保留原可用配置。
- 成功校验结果在重启后保留，不再每次打开都重新加载模型。文件或路径变化、主动重新校验时才重新检查。
- 模型文件或运行环境不存在时，提示重新选择对应目录或 Python，不自动重新下载。
- 未开始下载时隐藏进度；已验证版本隐藏下载区，进行中的下载仍可取消。

### 反推提示与结果管理
- 增加目标/角色提示及“网络角色”选项：能够可靠识别时优先使用角色 Tag，不确定时保留外貌描述。
- 生成预算说明默认折叠，明确搜索与最终复测的图片数量。
- 新增清空迭代结果入口，用户可选择保留图片或同时移至回收站；默认保留图片，不清理模型、参考图及其他任务资料。

### 校验与兼容性说明
- 本地实测完整版 PE-G50 在 RTX 5070 上完成文件完整性检查、模型加载与评分；独立进程重启后复用已保存结果，不再启动 Python 校验。
- 部分旧运行环境仅支持完整版，会拒绝轻量版资源。请为轻量版选择兼容环境；本版本不会将另一模型的成功状态误用于轻量版，也不宣称旧环境已兼容轻量版。
- 本次功能变更主要针对 Windows 的本地 Artist Detective；移动端同步应用版本 2.4.3、构建号 162，不宣称移动端支持该本地 CUDA 模型。
- Agent 独立组件保持原版本，不重复打包到安装包。本地模型与运行环境仍由用户按需下载。

### 下载与平台
- Windows x64：`Langbai-NovelAI-Studio-Setup-2.4.3.exe`（安装版）、`Langbai-NovelAI-Studio-2.4.3.exe`（便携版）。
- macOS：通用 DMG / ZIP，未签名；Linux x64：AppImage。
- Android：`app-release.apk`；iOS：`novelai-mobile-unsigned.ipa`，需自行签名或侧载。
- 发布前检查桌面构建、打包内容、Windows 安装升级、Agent 启动、macOS 双架构及移动构建与 Android 签名连续性；不将自动化验证表述为实体手机验收。
