# v2.7.6 — 中转站介绍预览与桌面启动反馈

发布日期：2026-11-04（Asia/Hong_Kong）。

## 本版本更新
- Windows、macOS、Linux、Android、iOS的中转站推荐入口先展示本地介绍弹窗：Logo、nai.langbai.cc域名、第三方非官方站点简介及完整1193×766网站截图，按比例展示、不裁切；点击图片不跳转。
- 保留“进入网站／返回”。只有明确进入才通过系统浏览器打开固定网址；返回、遮罩、Esc／系统返回不打开网站。沿用五语言、焦点保护、重复点击保护和减少动画；不改账号或API配置。
- 桌面端在大型界面模块加载前显示独立启动提示；超时或模块异常时提供重新加载入口。主进程检测启动超时、加载失败及早期渲染进程退出，提供手动重试，不清空用户数据、不自动重发生图请求；就绪后不干预正在运行的界面。
- 这是修复“启动没有可操作反馈”的机制，不宣称解决操作系统资源不足。此前曾观察到Chromium子进程15秒未建立连接退出；该日志不能证明预览图导致故障，也不能单凭它确定系统根因。

## 范围检查与交付
- 推荐弹窗已有24项手机回归、7项桌面测试、11类隔离真实Chromium交互检查通过；五语言、小屏／横屏、大字、返回与进入、重复点击、失败反馈和图片比例均有范围证据。手机截图是组件渲染，不是红米或iPhone真机截图。
- 本次新增启动健康机制测试，类型检查及实际Windows包启动／推荐弹窗检查单独记录于verification.json；不得用组件通过代替实际包启动检查。发布要求实际Windows包能够进入可用界面并显示预览弹窗。
- 五个平台从同一源码新构建，版本2.7.6，移动构建号197；不重命名旧包冒充新构建。

## 明确未完成的验收与安装限制
- 未完成五平台完整功能、厂商ROM、覆盖升级、GPU／本地模型、真实付费生成及完整账号／网络矩阵验收。Windows启动与推荐入口检查不等于所有功能验收。
