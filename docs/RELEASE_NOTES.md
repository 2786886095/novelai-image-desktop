## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.8.0.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.8.0.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.8.0-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |

| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.8.0.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.8.0 更新内容

- 随机画师串抽卡现在直接提供独立的完整生成参数区，可选择 6 种 NovelAI 合法尺寸并自动回填宽高，也可自行输入模型、尺寸、Steps、CFG、CFG Rescale、采样器、负面预设与开关；支持同步主生成页或恢复软件默认值。
- 修复数字输入过程中被逐键强制改值的问题；抽卡数量、画师数量、Seed、尺寸与权重浮动会在失焦或回车时统一校验，0% 权重浮动也可正常使用。
- 重做权重微调、参考预设筛选与历史图片悬停操作的栅格和基线，统一 44px 控件高度，修复按钮拉伸、图标越界及搜索/下拉不对齐。
- 接入 NovelAI `https://image.novelai.net/user/data` 返回的官方 V5 Opus 额度：仅选择 V5 时在桌面生成栏账户区、移动端生成页顶栏显示进度与约可生成张数；点击可查看普通分辨率、最多 28 步、每日补充速度及完整进度条，Anlas 余额与本次生成报价仍独立显示。软件可见时每分钟自动刷新，手动刷新直接重请求官方接口；失败时明确标记为“上次成功数据”，不会伪装成实时同步或把额度改成 0。
- 优化图片删除和大批量抽卡性能：历史备份改用元数据级轮换，连续删除按单项回滚；清空抽卡结果立即更新界面，临时文件以受控并发在后台清理。
- 抽卡状态持久化改为合并写入，减少生成过程中反复同步写 localStorage；生成进度不再强制抢回滚动位置。
- 移动端同步修复画师数量上限、Seed 范围、0% 权重浮动和尺寸输入提交逻辑，并加入 V5 Opus 用量弹窗。
- “恢复图片原数据”最近导入图改存桌面/移动端稳定用户数据目录，关闭并重启软件后仍会恢复；两端历史记录及分组内图片均新增一键查看并恢复原数据入口。
