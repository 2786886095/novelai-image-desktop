## Langbai NovelAI Studio 2.4.9

### v2.4.9 更新内容
- 角色提示词新增独立启用／暂停开关：暂停保留正负提示词与位置，不参与生成；重新启用即可恢复。状态随生图配置及角色预设保存，旧配置默认启用。支持 NovelAI V4.5 与 V5。
- 随机画师串抽卡支持 V4.5、V5 Full／Curated，并保留选择的模型；目标相似迭代仍限 V4.5，避免切入不支持的模型。
- #42：历史与素材支持拖入、粘贴图片并恢复可识别原数据；加载图像与应用参数操作分离。
- #43：生成主预览支持左右键切换当前历史与素材图片，保留滚轮缩放及点击大图。
- #44：新增复制图片时保留原数据开关，默认关闭；开启后 Windows 复制、粘贴保留原 PNG 元数据，并提供标准位图兼容。
- #45：放大预览按真实显示图像区域判定点击，空白区域不会误开；历史与主预览使用一致的多图浏览器。
- #46：收藏夹支持应用到生成，复用原数据恢复流程。
- Windows、Android、iOS 共用功能源码同步；保留已验证的账号、中转、积分缓存、代理、智能体和模板行为。

### 下载与验证范围
- 安装版：`Langbai-NovelAI-Studio-Setup-2.4.9.exe`。
- 便携版：`Langbai-NovelAI-Studio-2.4.9.exe`。
- 本次仅发布 Windows x64 安装版与便携版，附带 `latest.yml` 和 `verification.json`；不发布 Android、iOS、macOS、Linux 安装包。
- 沿用桌面与共享源码回归、原生运行时、实际 NSIS 解码、干净安装与旧版升级、用户数据保留、按需组件启动和离线复用等正式门槛；公开制品哈希必须与验证字节一致。
- Windows 安装包未配置代码签名，系统可能显示 SmartScreen 提示。共享代码及自动化回归不等同于移动真机手势验收。本轮未使用付费生图接口，不代表所有第三方站点均已实号验证。
