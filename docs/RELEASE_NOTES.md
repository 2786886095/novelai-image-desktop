## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.9.9.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.9.9.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.9.9-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.9.9.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.9.9.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.9.9 更新内容
- 彻底重做 Android/iOS 全屏重绘蒙版的预览底层：改为固定大小的 NovelAI **8×8 源图栅格蒙版**，直接更新受影响的格子，不再随每次移动累积并重放历史笔迹；绘制成本不再随着笔数持续增长。
- 蒙版导出、编辑器叠加预览和完成后的页面预览统一使用同一份最终栅格结果；相邻格按行合并绘制，橡皮擦、反选、圆形与方形画笔仍保持像素级一致。
- 全屏编辑器始终让半透明遮罩与原图对齐叠加，并提供“显示/隐藏蒙版”开关；移除遮挡画面的浮层手势提示。返回局部重绘页后仍可单独打开黑底白色的“将发送的遮罩”精确预览，“编辑蒙版 / 预览遮罩 / 清空蒙版 / 局部重绘”固定放在图片预览之前，不再被高图片或空白区域推到屏幕外。
- 完成后的操作键、状态与原图/蒙版对比预览合并为一个紧凑面板，对比预览可随时隐藏；桌面端和移动端均可选择蒙版显示颜色与透明度，但发送给 NovelAI 的仍是标准二值蒙版。
- 删除图生图与局部重绘界面中无实际作用的“噪声”参数；桌面端、移动端和批处理请求统一固定发送 `noise: 0`，保留接口兼容性。
- 更新图片反推与提示词转换的 6 套 NovelAI V5 模板（Danbooru、自然语言、混合模式），精简冲突规则并完成多场景压力测试及 Grok、Gemini、Claude 交叉审定。
- 统一随机画师、输入画师串抽卡与 V4.5→V5 修复器的候选卡片交互：图片按真实宽高比展示，支持双击或预览键查看大图，并继续使用彼此独立的收藏库。
- 修复“恢复图片原数据”页面的图片分组浮动标签被裁切；桌面端与移动端“关于我们”明确标注 NovelAI QQ 交流群。
- 新增 1200 次独立笔迹固定内存栅格测试、36 笔连续交互测试，以及“完成返回后操作键仍存在并可打开精确预览”等回归测试。
