### v1.4.6 更新内容

- **随机画师串抽卡（Windows、Android、iOS）**：每条画师串可精确指定组合 1～20 名画师，不再使用模糊的随机数量范围。
- 候选池可选择按 Danbooru 公开标签帖子数排序后的前 100～5000 名画师，默认前 1000 名；帖子数仅作为热度先验，不代表真实用户数量。
- “允许非画师词参与随机变异”现在明确发生在抽卡阶段：每条画师串额外抽取 2～6 个带 0.3～1.5 权重的风格词，覆盖画风、媒介/笔触、色彩、光影和氛围五类；用户填写的固定辅助提示词不会被随机改写。
- 每次抽卡只保留当前批次结果。未收藏图片只写入临时缓存，不进入永久输出目录或历史记录，并在下一次抽卡时自动清理；收藏后才会移入 `画风实验室-随机抽卡` 专用目录并永久记录。
- 生成失败的卡片新增“重试”按钮，使用原画师串、原种子和原参数手动重试，不会暗中更换本次配方。
- 收藏列表会跨会话保留，支持删除收藏、复制画师串、一键应用到生成，并可作为后续抽卡的偏好方向。
- 抽卡设置、变异类型、缓存状态、重试和收藏交互已补齐简体中文、繁体中文、英语、日语和韩语，并继续适配竖屏手机、横屏手机与平板布局。

### 使用与资源说明

- 未收藏抽卡结果仍会短暂存放在操作系统或应用临时目录，用于当前批次预览；它们不是永久保存文件。
- 单次抽卡数量不设产品层面的上限，但实际生成速度、内存占用和 NovelAI 请求稳定性仍取决于设备与网络，建议按设备能力分批生成。
- 所有 NovelAI 生图请求仍由用户自己的 Token 发起，实际 Anlas 规则与服务限制以 NovelAI 官方返回为准。
