# v2.7.4 — Android 紧凑工作台与真实交互动效

发布日期：2026-11-04（Asia/Hong_Kong）。

## 更新内容
- Android工作台顶部改为紧凑单行固定栏，正文独立滚动，保留底部导航和必要的生成操作，不再层层堆叠账号、标题、推荐与搜索占用空间。
- 切页菜单在固定顶栏下方居中向下展开，显示对应图标和当前页勾选，不覆盖顶栏。
- 设置入口按下立即有可见反馈并保留Material涟漪；设置子页从右侧滑入、返回反向退出，使用不透明页面避免两页文字叠影。主页面首次访问也有轻量过渡，固定顶／底栏不随正文移动。

- 保留现有功能与账号、文件、提示词、工作流、模板及用户数据。界面改进主要面向Android，Windows/macOS/Linux/iOS同步版本并重新构建，不宣称获得相同Android布局。
