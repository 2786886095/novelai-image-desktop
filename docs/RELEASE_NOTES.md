### v1.4.7 更新内容

- **随机画师串 A/B 对照抽卡（Windows、Android、iOS）**：开启“抽卡时额外加入随机风格词”后，每组画师串会生成两张图片。
- A 图仅使用画师串；B 图在相同画师串、固定内容提示词、Seed、尺寸和生成参数上额外加入 2～6 个带 0.3～1.5 权重的随机风格词。两张图仅有风格词这一处变量，便于直接判断风格词是否有效。
- 用户输入的生成数量现在表示“画师串组数”。例如输入 10，开启 A/B 对照后会生成 10 组、共 20 张图片；关闭风格词后仍是一组一张。
- 预览和结果卡片明确显示 `A｜仅画师串` 与 `B｜画师串＋随机风格词`，并展示 B 图实际使用的风格类别、词条和权重。
- A、B 可以分别收藏、分别失败重试、分别应用到生成页；每张卡片同时提供“复制画师串”和“复制完整提示词”，避免混淆生成来源。
- 收藏 B 图后，只有继续开启风格词并使用偏好抽卡时，系统才会参考该收藏的风格类别、词条和权重；关闭风格词时仍只参考画师标签。
- A/B 配对信息、收藏和临时结果兼容已有会话数据；未收藏图片仍只保留在临时缓存，并在下一次抽卡时清理。
- 简体中文、繁体中文、英语、日语和韩语文案已同步更新，移动端继续覆盖竖屏手机、横屏手机与平板布局。

### 使用与资源说明

- A/B 对照会让实际 NovelAI 请求数变为画师串组数的两倍；生成前请以界面显示的实际图片数为准。
- 未收藏抽卡结果仍会短暂存放在操作系统或应用临时目录，用于当前批次预览；它们不是永久保存文件。
- 所有 NovelAI 生图请求仍由用户自己的 Token 发起，实际 Anlas 规则与服务限制以 NovelAI 官方返回为准。
