## Langbai NovelAI Studio 2.3.5

### v2.3.5 更新内容

### 风格管理（电脑端 / 手机端）
- 新增独立「风格管理」页面，统一管理已保存的风格提示词：分类、搜索、编辑名称和内容、预览图管理。
- 支持拖拽调整自定义顺序，也可通过上下移动按钮排序。
- 支持 0–5 范围内手动输入评分，允许小数（包括 0.5 分档）。
- 管理页面及生成页的风格选择器支持默认顺序、自定义顺序、评分、创建时间、使用次数及名称排序。
- 支持一行一串批量导入，可用「名称 + Tab + 提示词」指定名称；预览图可按文件名或顺序关联。
- Quick Tag Cloud 条目可一键保存名称、提示词和预览图到风格库，再继续编辑。

### 预览与编辑体验
- 编辑页支持从最多 9 张预览图中选择列表封面；封面按原图比例完整显示，点击可翻看全部图片。
- 删除预览图需二次确认；删除封面后自动显示第一张剩余图片，取消编辑保留原数据。
- 进入编辑时隐藏管理页的搜索、分类及排序区，保留软件顶部导航；修复滚动操作导致整个窗口上移的问题。
- 评分、封面、自定义顺序等随预设保存；兼容已有风格数据。

### 说明
- 使用次数统计明确选择或应用风格的次数，不代表实际生成图片数。
- 本次覆盖 Issue #26 第一阶段的风格管理及单向导入需求；画风实验室双向同步、跨用户分享未纳入本次。
- Issue #24「有关程式开启」保持打开。
