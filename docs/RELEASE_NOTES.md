## Langbai NovelAI Studio 2.3.0

### v2.3.0 更新内容

#### 酒馆 AI 生图
- 修复双击图片后的预览偏移，图片和缩放控件居中显示。
- 修复原图删除、路径复用后，旧对话显示其他图片的问题；删除原图时同步关闭对应预览。
- 批量生成中途失败时保留已生成图片，并显示成功张数及失败原因。
- 精简模式说明、生成状态和提示词预设文案。

#### 图片与历史记录
- 修复删除失败返回较晚时，覆盖用户后来选择或生成的图片的问题。
- 修复同名图片并发保存和重命名冲突，避免文件覆盖。
- 图片地址加入记录版本，修复同一路径被复用时显示旧缓存的问题。
- 减少酒馆读取图片记录时重复访问磁盘。

### 安装包
- Windows 安装版 `Langbai-NovelAI-Studio-Setup-2.3.0.exe` 与便携版 `Langbai-NovelAI-Studio-2.3.0.exe`；macOS Universal DMG/ZIP、Linux AppImage。
- Android 稳定签名 APK；iOS IPA 未签名，需要自行签名。
- 移动端同步版本及共享文案；本轮图片生命周期和预览修复主要针对桌面端。

### 验证
桌面本地 1006 条测试通过，双 TypeScript 类型检查与构建通过。安装包通过各平台 CI 门禁后发布，包括 Windows、Linux、macOS 原生启动及图片编解码检查、Android/iOS 分析、测试与构建。未进行真实付费生图或移动端真机测试。
