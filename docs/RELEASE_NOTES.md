## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-1.7.3.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-1.7.3.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-1.7.3-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-1.7.3.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-1.7.3.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v1.7.3 更新内容

- 参考预设页新增“在线下载 / 本机预设”一级切换并默认进入在线目录，下载入口不再被本地预设列表挤到页面底部。
- 在线精准参考图仅在图片成功保存后创建“游戏 · 分类”分组；已有同名分组直接复用，并自动清理旧版本遗留的空游戏分组。
- 新增删除分组与二次确认。删除分组不会删除图片或预设，原有内容会安全移入“未分组”。
- 移除参考预设顶层页面不合适的右上角关闭按钮；选择器、弹窗和图片预览仍保留明确的关闭入口。
- 桌面端在线与本机预设均可选择每排 2–5 张并持久化；移动端在线目录支持自动布局或每排 1–5 张，改善图片过小和触控不便。
- 继续支持 Gitee 中国大陆优先线路、GitHub 自动回退、五语言名称与跨语言搜索、文件大小和实时下载进度；只下载每个角色形态选定的最佳 NovelAI 精准参考图。
- 桌面交互统一采用 WeUI 组件并以 GSAP 提供 240ms 轻量切换动画；移动端采用原生分段控件，同时适配系统“减少动态效果”设置。
- 修复移动端下载失败时残留空分组或预设记录的问题，并补充旧数据迁移、分组复用和安全删除的自动化测试。
