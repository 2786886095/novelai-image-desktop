## Langbai NovelAI Studio 2.5.1

### v2.5.1 更新内容
- #50：历史与素材侧栏可按钮一键收起／展开，或拖动分隔条向右收起、向左恢复；记住状态及展开宽度。
- #51：生成主图右键使用与历史缩略图共用的图片菜单；保留滚轮缩放、拖动平移和点击大图预览。
- 历史侧栏箭头改用居中的矢量图标。
- 重绘支持“按原图尺寸”与“自定义尺寸”，自定义尺寸独立保存，不影响生成页。
- 自定义重绘复用总分辨率、画面比例、宽高及实际 MP 控件；无效尺寸阻止报价与生成，不静默修改尺寸。
- 重绘尺寸与生成页统一为“提示词工具栏 → 尺寸 → 种子”顺序，Windows、Android、iOS 共用源码同步。
- 保留 v2.5.0 翻译目标语言与对照预览、角色提示词开关、V4.5／V5 随机画师串及 #42–#46 修复。

### 下载与验证范围
- 安装版：`Langbai-NovelAI-Studio-Setup-2.5.1.exe`。
- 便携版：`Langbai-NovelAI-Studio-2.5.1.exe`。
- 仅发布 Windows x64 二进制，附 `latest.yml` 和 `verification.json`；共用移动源码版本为 2.5.1+170，不发布移动安装包。
- 正式发行要求桌面与共享移动源码回归、打包运行时、实际 NSIS 解码、干净安装及旧版升级、数据保留、按需组件启动和离线复用全部通过，公开制品哈希须与同轮验证字节一致。
- 重绘尺寸及顺序已经实际 Electron 组件交互验证，Android／iOS／iPad 布局经过模拟组件验证；不代表移动真机验收。
- Windows 安装包未配置代码签名，可能出现 SmartScreen 提示；本轮不调用付费生图接口。
