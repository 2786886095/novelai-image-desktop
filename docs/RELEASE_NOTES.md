## Langbai NovelAI Studio

请根据你的操作系统下载对应安装包：

| 系统 | 安装包 | 安装说明 |
| --- | --- | --- |
| 🪟 **Windows**（便携版，x64） | `Langbai-NovelAI-Studio-2.0.1.exe` | 双击即用，无需安装 |
| 🪟 **Windows**（安装版，x64） | `Langbai-NovelAI-Studio-Setup-2.0.1.exe` | 安装向导可自选路径、创建快捷方式；支持软件内一键更新 |
| 🍎 **macOS** (Intel + Apple 芯片通用) | `Langbai-NovelAI-Studio-2.0.1-universal.dmg` | 拖入「应用程序」；**未签名**，首次打开请右键 →「打开」 |
| 🍎 **macOS**（压缩包，同上通用版） | `Langbai-NovelAI-Studio-2.0.1.zip` | 解压后即为 `.app`，同样需右键「打开」 |
| 🐧 **Linux** (x64) | `Langbai-NovelAI-Studio-2.0.1.AppImage` | `chmod +x` 后直接运行 |
| 🤖 **Android** | `app-release.apk` | 直接安装；需允许「未知来源」 |
| 📱 **iOS** | `novelai-mobile-unsigned.ipa` | **未签名**，需使用 AltStore / Sideloadly 等工具自行侧载 |

> 桌面端与移动端均为 **API-only** 客户端，需要自备 NovelAI Persistent API Token。

### v2.0.1 更新内容
- 转换页新增 V4.5 / V5 模板切换；设置中心可分别查看和编辑反推、转换的两套版本模板，版本规则互不混用。
- 输入画师串抽卡改为让所有有效 Tag 在用户设定范围内分别随机权重；V4.5 画师串修复器继续按旧权重的 1/3～1/2 迁移，两种工具职责分离。
- 三套画师工具使用彼此独立的收藏夹，并迁移恢复随机画师串旧收藏；输入画师串与 V4.5 修复默认生成 10 组。
- 统一三套画师工具的结果卡片、原比例预览和操作位置；输入画师串与 V4.5 修复均可复制画师串或完整提示词，展示与复制结果末尾固定为一个英文逗号。
- 局部重绘修复“画笔透明度 100% 仍偏透明”的显示问题；蒙版颜色顺序调整为白、黑、红优先，其余颜色随后。
- 优化深色模式下反推、转换与设置卡片的背景和边框层级，减少突兀浅色块与界面割裂感。
- 补充模板版本选择、独立收藏迁移、全 Tag 随机权重、末尾逗号和蒙版透明度等回归测试。
