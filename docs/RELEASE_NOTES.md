## Langbai NovelAI Studio 2.5.2

### v2.5.2 更新内容
- 新增六款可离线使用的风格中文字体：霞鹜文楷轻便版、小赖、悠哉、霞鹜漫黑、得意黑、思源宋体 CN。字体原始文件与许可证随软件打包，三端使用相同字体；不占用户导入名额，不安装到系统。
- 全局字体切换覆盖正文、提示词、对话及参数；保留自定义 TTF/OTF 导入。缺字使用系统回退，不再把系统字体别名当成有明显风格差异的字体。
- 全局字号放大改为分层响应：正文与提示词按所选比例放大，导航、按钮、标题适度缩放；修复 200% 字号下三栏拥挤、按钮文字竖排、重叠和横向溢出。
- 外观设置的字体预览、滑块与输入控件统一全局 UI 样式；宽屏、窄屏及移动端自适应布局同步。
- 角色名称默认只展示名称及铅笔按钮，点击后才进入编辑，确认保存或取消；保留角色暂时开关、提示词和位置数据。
- 生图、重绘、增强及后期新增独立自动对比开关，默认开启；关闭后仍可手动查看。重绘笔刷的正方形/圆形图标正确区分。
- 保留 v2.5.1 原图/自定义重绘尺寸、统一尺寸位置、侧栏按钮/拖动收放及持久化、主图右键菜单、滚轮缩放与点击预览，以及此前翻译预览、NovelAI 中转和随机画师串模型修复。
