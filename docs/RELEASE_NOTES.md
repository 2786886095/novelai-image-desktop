# 更新记录

## Latest · 本次更新

本 fork 在原项目最新源码的基础上维护，以下为相对原版的改动。

- **增强改为官方倍率**：「生成 → 增强」的输出倍率改为与 NovelAI 官方一致的 1× / 1.5× / MAX。原来的 2× 对 832×1216 等常见尺寸会超过官方像素上限而无法执行；1.5× 按官方方式对齐 64 像素网格（832×1216 → 1280×1856）。MAX 仍使用官方的 upscaled_enhance，在上限内最高约 2×。「后期 → 超分」的说明补充了官方超分每次固定 2× 的提示。
- **提示词库常驻显示**：正面提示词框下方常驻「正面预设 / 保存当前 / 自定义提词」，负面提示词框下方常驻「负面提示词库 / 保存当前」，不再藏在工具栏的「更多」菜单里。
- **正面预设可追加**：正面预设新增「追加到当前提示词」，与负面词库一致；角色预设会追加到现有角色之后，在单个角色行内追加则续写该角色的提示词。
- **提示词标签**：正面预设、负面词库和自定义提词块都可以设置标签，可按标签筛选（含「未加标签」），搜索同时匹配名称、内容和标签，输入 `#标签` 可精确筛选。标签会随设置、负面词库导入导出和数据备份恢复一起保留。
- **提示词联想修复**：点击输入框其他位置、移动光标、按 Esc、点击外部或失去焦点时联想列表会关闭，失焦后不再弹出迟到的联想结果；选中的标签总是替换触发联想的那个词，不会插到之后点击的位置；补全多词标签（如 long ha → long hair）不再重复已输入的词。
- **更新来源**：软件内检查更新只检查本 fork 的发行版，不会再提示原项目的版本。

**验证范围**：桌面端类型检查、全部单元测试与生产构建在 Linux 环境通过；提示词库、标签和联想修复已在浏览器中按实际界面验证。未在 Windows / macOS 真机上验证安装包，也没有进行真实的 NovelAI 生图验收；1.5× 增强的尺寸规则依据社区对官方网页的实测资料。
