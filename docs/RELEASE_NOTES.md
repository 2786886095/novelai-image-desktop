# 更新记录

## Latest · 本次更新

本 fork 在原项目源码的基础上维护，以下为相对原版的全部改动。本版起只提供 Windows 与 macOS 的简体中文桌面版。

### 新功能与改进

- **增强改为官方倍率**：「生成 → 增强」的输出倍率改为与 NovelAI 官方一致的 1× / 1.5× / MAX。原来的 2× 对 832×1216 等常见尺寸会超过官方像素上限而无法执行；1.5× 按官方方式对齐 64 像素网格（832×1216 → 1280×1856）。MAX 在 V5 模型上使用官方的 upscaled_enhance，其他模型按约 2×（受像素上限约束）做图生图增强。「后期 → 超分」的说明补充了官方超分每次固定 2× 的提示。
- **提示词库常驻显示**：正面提示词框下方常驻「正面预设 / 保存当前 / 自定义提词」，负面提示词框下方常驻「负面提示词库 / 保存当前」，不再藏在工具栏的「更多」菜单里。
- **正面预设可追加**：正面预设新增「追加到当前提示词」，与负面词库一致；角色预设会追加到现有角色之后（局部重绘页按局部重绘模型的角色上限检查），在单个角色行内追加则续写该角色的提示词。
- **提示词标签**：正面预设、负面词库和自定义提词块都可以设置标签，可按标签筛选（含「未加标签」），搜索同时匹配名称、内容和标签，输入 `#标签` 可精确筛选（支持带空格的标签）。删除最后一个带当前筛选标签的条目后，筛选自动回到「全部」。标签会随设置、负面词库导入导出和数据备份恢复一起保留。
- **提示词联想修复**：在输入框内任意位置点击、移动光标、按 Esc、点击外部或失去焦点时联想列表都会关闭，失焦后不再弹出迟到的结果；选中的标签总是替换触发联想的那个词，不会插到之后点击的位置；回车选择当前高亮的项，列表在静止的鼠标下弹出或滚动时不会误选；列表不会被面板遮挡，方向键会把高亮项滚动到可见位置；补全多词标签以及 `{long ha`、`1.2::long ha` 这类带权重的写法时不再重复已输入的词，也不会删掉光标后的中文或换行。
- **其他修正**：下拉菜单中长名称的排版；三处直接显示内部键名的文字（删除确认、保存按钮、AI 反推任务名）；在线参考目录无法访问时改为读取安装包内置的目录；界面错误提示不再带英文的 “Error invoking remote method” 前缀，部分网络、第三方服务或系统返回的错误仍可能显示英文原文；备份恢复时账户验证失败或凭据无法解密会给出中文原因。
- **账户无法解密时仍可启动**：上次使用的账户在本机无法解密时（例如从其他电脑复制了设置），软件会取消选择该账户并正常启动，不再停在启动页；可在账户管理中删除该账户后重新添加。
- **项目链接**：「关于」页与首次使用引导中的项目链接改为本 fork，原作者信息保留。

### 精简

- **只保留桌面端**：删除 Android、iOS 与 Linux 客户端及其构建配置。
- **删除生图智能体**：移除「生图智能体」标签页（聊天式生图助手及其模型服务商配置、对话记录）。设置中的「本地 MCP 服务」保留，Claude Code、Codex 等外部智能体仍可通过 MCP 调用本软件。
- **删除本地 Agent 组件**：移除仅 Windows 的本地 Agent（Studio Harness）组件及其插件、组件下载与更新。
- **删除本地 ComfyUI**：移除本地 ComfyUI 工作台、环境引导与相关设置；读取 ComfyUI / SD 图片中的生成参数不受影响。
- **删除软件内更新**：软件不再检查、下载或安装更新，新版本请从 Latest 手动下载。
- **只保留简体中文界面**：移除繁体中文、英语、日语、韩语界面与语言切换。提示词翻译仍可选择英语、日语等目标语言，其中「跟随软件语言」现固定为简体中文，原先使用其他界面语言的用户可在翻译设置中重新选择；中文标签转换与 AI 反推 / 转换的 Tag / 自然语言 / 混合输出不受影响。

### 数据与升级

- 直接覆盖安装原版或本 fork 的旧版即可，设置、历史与作品原样沿用。原项目及旧版本的设置和 `.naisbackup` 备份仍可导入；已删除功能的数据会被忽略，界面语言统一为简体中文。
- 安装提示不再提到已删除的功能。升级时仍会检查旧版数据（包括旧版本地 ComfyUI 数据）是否位于程序目录内，并备份旧版工作区数据；发现问题时会停止安装或卸载并附上检查信息，以免误删。
- 装过本 fork 带软件内更新的旧版时，它会提示有新版本，但本版不提供自动更新文件，软件内下载会失败，请从 Latest 手动下载安装包。
- **安装包未签名**：Windows 安装版与便携版未做代码签名，SmartScreen 可能提示“未知发布者”；macOS 通用 DMG / ZIP 未签名、未公证，若系统拦截，请核对下载来源，并按 macOS 提供的应用打开流程处理。请只从本仓库的 Latest 下载，并核对发行页显示的附件 SHA256。

**验证范围**：桌面端类型检查、全部单元测试与生产构建在 Linux 环境通过；在 Linux 上交叉打包 Windows 程序目录并通过运行依赖检查；提示词库、标签、联想、下拉菜单与错误提示已在浏览器中按实际界面验证，风格与负面词库等 12 项原生界面验收在 Linux 虚拟显示下通过。发行页的 Windows 安装包与 macOS DMG / ZIP 未在 Windows / Mac 真机上安装验证，也没有进行真实的 NovelAI 生图验收；1.5× 增强的尺寸规则依据社区对官方网页的实测资料。
