### v2.2.4 更新内容
- 酒馆 AI 新增可导入、重命名和删除的 JSON 对话预设；同一套任务预设可供酒馆、AI 反推与提示词转换使用，旧工作区会安全迁移。
- 修正酒馆生图参数优先级：默认严格使用右侧创作参数，空风格提示词不会继承生成页内容；用户明确指定参数时才按本次要求覆盖。
- 修复酒馆对话偶发删除无响应，增强文字与图片复制反馈；复制提示调整到对话区上方居中，预览支持点击空白关闭。
- 在线画廊改进瀑布流紧凑排列、原比例卡片与多图横向浏览；详情和双击预览按横竖图自适应完整展示。
- 桌面端与移动端统一分页、总页数、跳页和后台换页体验；加载下一页时保留当前内容，完成后再切换。
- 画廊下载支持单图与整组保存，并记住首次选择的下载目录；移动端补齐同类预览、下载和布局适配。
- 修复统一下拉组件的弹层定位、键盘导航、焦点恢复、无障碍标签和超长列表性能问题。
- 优化更新过程提示、入场动效、跨工作区切换残影、反推与转换请求链及错误反馈。

> v2.2.4 包含此前版本的全部功能与修复，建议桌面端和移动端用户更新。
