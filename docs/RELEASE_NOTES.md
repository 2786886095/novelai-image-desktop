# 更新记录

## Latest · 本轮候选更新（尚未正式发布）

- **图片隐私**：关闭保留元数据时，保存与复制均清除 PNG 附加元数据和整图已知像素隐写载体，再重新编码；保留尺寸与透明通道，像素可能轻微变化，文件不保证更小。历史图片、文件名、工程及备份 ZIP 不会自动匿名化。

- **选区重绘**：保留原图分辨率，只适配选区工作尺寸后贴回；支持返回编辑时恢复重绘前原图、蒙版与选区，移动端补齐对应流程。
- **AI 反推**：兼容 JSON 代码围栏与结构化结果；拒答、截断、无效结果或取消时保留原提示词和已有结果，不把拒答当作提示词应用。
- **AI 转换**：失败或取消时保留已有双版本结果。
- **诊断保护**：在已覆盖的错误及日志边界脱敏配置的 AI 密钥（含 URL 编码形式），不改写成功的提示词；不承诺任意未知编码均可识别。
- **图片导入**：完整解码通过后才替换当前工作图，损坏图片不清空现有图。

- **验收与构建**：修正小窗口画布与导航菜单的测试定位、移动端蒙版及请求参数夹具，并加强超时及未完成证据处理；五端结果仍需按最终同源执行证据确认。
