## Langbai NovelAI Studio 2.5.3

### v2.5.3 更新内容
- 修复普通生图正常、目标风格自动迭代却出现 `[WinError 10061]` 的网络路径不一致问题：自动迭代现在复用软件的系统代理、PAC、手动 HTTP/SOCKS 或直连策略。
- 每次任务固定使用启动时选定的账号、图片接口和网络设置。中转地址的路径前缀保留；不会擅自切换到官方站点，也不会将官方 Token 发给中转站。
- 本地传输桥仅监听回环地址，逐任务鉴权；上游凭据不放入命令行。连接故障显示可操作的说明；提交状态不确定时不自动重放，避免重复计费。
- 目标风格自动迭代仍仅使用 NAI 4.5 Full；随机画师串抽卡保留 NAI 4.5 / V5 支持。
- 保留 v2.5.2 的六款离线字体、响应式字号、点击铅笔编辑角色名、自动对比开关、重绘尺寸及此前功能。

### 下载与验证范围
- Windows x64 安装版：`Langbai-NovelAI-Studio-Setup-2.5.3.exe`；便携版：`Langbai-NovelAI-Studio-2.5.3.exe`。
- 附 `latest.yml` 与 `verification.json`；共用 Android/iOS 源码版本为 2.5.3+172，本次不发布移动二进制。
- 保留完整源码回归、共享移动源码分析及测试、实际打包运行时与字体、真实 NSIS 解码、干净安装、从 2.4.0 升级的数据保留、按需组件启动与离线复用门槛。
- 网络修复已用真实 Python 适配器和本地 TCP 代理复现“原版连接拒绝、修复版收到有效 PNG 且缓存不重复请求、回滚版恢复原行为”；测试使用合成图，无付费生图、GPU 质量或用户现场验收。不能据此断言所有用户的连接拒绝都由同一原因引起。
- Windows 二进制未配置代码签名，可能出现 SmartScreen 提示；移动组件测试不代表 Android/iOS/iPad 真机验收。
