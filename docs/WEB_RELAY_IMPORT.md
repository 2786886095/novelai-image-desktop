# 网页一键导入中转账号（本地候选）

网站在密钥“复制”按钮左侧提供“一键导入”，先由网站后端签发一次性导入码，再打开：

```text
langbai-novelai://relay/import?code=<43位base64url一次性导入码>
```

这不是把密钥放在链接里。工作台只接受精确 scheme、relay 主机、/import 路径及唯一 code 参数；额外参数、完整密钥、外部服务器、端口、userinfo、fragment、编码别名或其他路径均拒绝。网站按钮与签发接口由网站方实现，本候选不假称已经修改或部署网站。

客户端只向 `https://nai.langbai.cc/api/workbench/import/exchange` 发出一次 JSON POST `{ "code": "..." }`。不携带客户端凭据、Cookie，不跟随重定向、不重试。响应须为 JSON、version=1、type=novelai-relay、指定名称，两个 API 地址必须为 `https://nai.langbai.cc`（允许末尾斜杠）。错误响应正文不进入界面／日志。接口404/501/503或非JSON时明确提示“接口尚未就绪或格式不兼容”；失败后需回网站重新点击。

账号沿用现有系统加密凭据库，以地址和密钥去重。默认名 `Langbai Novelai生图`，重复则使用最小可用数字后缀。没有任务时选中账号并尝试只读积分刷新；无余额或刷新失败不撤销账号保存。主进程检测到账户操作、智能体、ComfyUI、画风迭代或本地组件任务时，仅保存／复用，不切换账号或刷新当前任务账号；提示“已添加，任务结束后可切换”，不会在任务结束后偷偷自动切换。

## 安装与首次启动

- **Windows 候选目录版**：完整保留 EXE 与旁边的 resources 等文件，放到长期保留的位置后首次运行。正常启动时为当前用户注册协议，无需在网站输入本地路径；浏览器首次唤起时按浏览器自己的提示确认打开应用。不要只复制 EXE。
- **Windows 便携单文件版**：首次运行后使用 `PORTABLE_EXECUTABLE_FILE` 指向的真实外层 EXE 注册，不使用临时解压出的 process.execPath。移动／删除 EXE 后需要从新位置再启动一次。若找不到稳定文件或路径位于临时目录，将不注册错误路径；请改放到固定目录。
- **Windows 安装版**：重新构建的 NSIS 包声明同一协议，安装后启动一次。旧发行版不具备此功能，不会因网站按钮出现而自动获得支持。
- **macOS**：需要重新构建含 CFBundleURLTypes 的应用，放入 Applications 后启动一次；在 app.ready 之前监听 open-url。此 Windows 候选不代表完成 macOS 实机验证。
- **Linux**：需要安装／启用含 x-scheme-handler/langbai-novelai 的桌面入口（AppImage需桌面集成）；运行时优先使用真实 APPIMAGE 路径，不注册临时挂载路径。若桌面环境不支持自动关联，请用其默认应用设置选择本工作台。未完成 Linux 桌面环境实机验证。
- 开着软件、未打开及初始化未完成时均排队接收；系统重复事件在进程内按摘要去重。请求前先将仅含高熵码 SHA256 摘要的使用记录原子落盘，跨进程重复也不重新兑换。记录损坏／写入失败会停止请求而不是冒险重试。记录上限10000条，达到上限停止兑换并提示回网站，不静默清空历史。原链接、码与密钥不写入该记录、剪贴板或应用日志。

## 验证边界

仅使用虚拟凭据、固定响应的网络替身和真实账号库方法验证；未读取用户真实密钥、未兑换真实导入码，也未进行付费生图。协议关联的单元测试不是 macOS/Linux 或浏览器端到端认证。网站接口是否已部署以真实服务方上线状态为准，不伪造成功。保留当前源码版本元数据，不为本功能再升级版本或发布 GitHub Release。
