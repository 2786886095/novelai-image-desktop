# 更新记录

## Latest · Android 新导航与创作界面、五平台同步更新

### 功能变更

- Android 采用新的导航与创作界面：底部主导航、“全部功能”目录与成员条保留原有 15 个目的地和 7 个工具，导航身份与数据键不变。iOS 及桌面界面保持原样。
- Android 窄屏（320dp）修正：图库筛选改为按内容宽度的单行筛选药丸（不低于 48dp，放不下时整颗换行，不拆词；过长的分组名在药丸内单行以省略号截断，在下拉菜单中最多显示两行，超出部分仍以省略号截断）；全屏提示词编辑器的完整字段名移到工具行下方，不再被截成省略号；卡片右上操作贴齐末端；从“全部功能”或深链选中的成员会自动滚入可见区域（减少动效时立即定位）。
- 系统与应用字体倍率照常生效；生成、确认、收费、不重放、账户与备份逻辑均未改变。本地 Agent 组件和画风自动迭代仍仅 Windows，其他平台不支持的项目不计为通过。

### 发行与验收边界

- **本轮授权与发行方式**：维护者本轮明确要求“直接发布 GitHub”，并批准接手直接发布五个平台；本版不再等待追加本地／原生功能验收。这是本轮直接发行授权，不是沿用 v2.6.8 的历史豁免；原正式验收门保持独立，不将未完成项目改记为通过。
- **制品来源**：版本为 `2.6.9+189`，五平台安装包基于源码提交 `860ce1097b763b4d51466f426e1eeaaf230e08e1`。[桌面构建 41161315930](https://github.com/2786886095/novelai-image-desktop/actions/runs/41161315930) 与 [移动构建 41161319283](https://github.com/2786886095/novelai-image-desktop/actions/runs/41161319283) 均已成功。构建成功不等于功能认证；发布说明等元数据提交与安装包源码须在 verification.json 中分别记录，不把旧提交的验收改绑到新源码。
- **完整正式门未完成**：同源 195 个声明单元中的 187 个必需单元尚未全部完成正式原生验收；另外 8 格为 Windows 专属能力在其他平台记为不支持，而非通过。本版不声称全功能验收通过，也不以已打包、局部测试或版本同步替代完整门。
- **Windows 画风迭代**：尚无本轮同源的三个完整 GPU 场景证明。等待阶段物理内存未达到准备准入门槛，完整场景未启动；未关闭用户程序，不将旧版受控显存峰值测量计为本版正式通过。
- **iOS 目录与保存链**：既有目录选择宿主驱动曾失败，完整系统目录选择／权限授权／保存及历史关联链仍未认证；该驱动失败本身不等于已确定产品根因，也不声明这一链路已修复验收通过。
- **Android 局部诊断**：[原生诊断 41160409971](https://github.com/2786886095/novelai-image-desktop/actions/runs/41160409971) 的 core／os／ui 三组成功，但属于有界诊断，日志仍有明确的未认证范围，不能据三组绿色状态推导五平台完整门已通过。
- **安装与更新边界**：实际文件、SHA256、签名与清单核验以 Latest 的 verification.json 为准。本轮未完成的覆盖升级、Agent 启动或自动更新链不因构建、Latest 标记或存在 latest.yml 而自动认证；建议从 Latest 手动下载安装，不承诺未被实际协议与清单证实的软件内自动升级。
- Linux 安装包验收与支持基线为 Ubuntu 24.04 LTS（x86_64）；Ubuntu 26.04 已观察到 Sharp／Electron 图像运行时卡住，当前不支持；其他发行版尚未验收。
- iOS 仅提供未签名 IPA，须自行签名／侧载，不能直接安装到普通 iPhone，也不是 App Store／TestFlight 版本。Windows 安装包无 Authenticode 签名，macOS 未公证，系统可能出现信任提示。
- 回环合成服务验收不证明远端模型画质、真实生图成功或实际扣费；本版没有使用真实账户或付费生成进行验证。各平台实际附件、哈希与签名信息见 Latest 附件中的 verification.json。
