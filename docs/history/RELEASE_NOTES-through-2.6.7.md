# 更新记录

## 2.6.7 · Anthropic Messages 思考强度

- **生图智能体思考强度**：桌面端与移动端为已知支持 adaptive thinking 的 Claude 模型正确发送 `thinking: { type: "adaptive" }` 及所选低／中／高对应的 `output_config.effort`。`auto` 不注入这两个字段，交由服务端默认处理。按明确模型集合识别受支持模型及有限网关别名；旧版、未知及未来模型不推定支持，不强制切换。
- **采样与失败行为**：显式 adaptive 时省略不兼容的 `temperature`／`top_p`；自动模式保留 Claude Opus／Sonnet 4.6 的原采样兼容行为，已知始终思考模型省略不支持的采样项。保留工具、图像块、端点、认证头及输出上限，不自动增加 `max_tokens`；HTTP 400 原样报错，不静默降级或重试。
- **已有定向验证**：62 项桌面端与 52 项移动端回归、TypeScript 类型检查及 Dart 分析已通过。请求验证仅使用脚本化 HTTP 与本机回环夹具，未向真实 Anthropic 或第三方中转端点发起验证；不能据此承诺任意中转站或未知模型兼容。
- **平台制品与证据**：各平台包、签名、安装与更新限制以 [Latest](https://github.com/2786886095/novelai-image-desktop/releases/latest) 的实际附件及验证证据为准；源码同步本身不代表五端原生验收完成，也不单独证明安装验证或自动更新可用。当前源码入口为 [main](https://github.com/2786886095/novelai-image-desktop/tree/main)。

既有支持范围保持不变：本地 Agent 组件与画风自动迭代仅承诺 Windows，macOS／Linux／Android 的这两项共 6 格为 not-supported、不计通过；生图智能体等其余 37 项功能的四端范围不变。本次未新增 150 个必需功能／平台单元的完整验收，也未新增 GPU 或五端实机验收。Windows 画风自动迭代的三个 GPU 原生场景仍未完成。iOS 仅为附加的未签名 IPA 打包范围，需自行签名，不能直接安装到普通 iPhone，不是 App Store／TestFlight 版本。平台签名、安装及更新能力以实际制品证据为准。

## Latest · 本次更新

- **生图智能体 TXT 附件**：只附加 TXT、没有输入文字时，将可读附件正文纳入本次用户消息，不提升为系统指令；保留附件身份与上下文边界。
- **附件与聊天反馈**：显示读取、就绪及发送状态，改进附件列表、对话切换和窄屏交互；失败草稿可明确恢复，不覆盖后续编辑，不自动重复提交结果未确认的消息。
- **画风迭代 2xx 响应**：接受成功状态范围内的合法结果，仍须通过 ZIP、图片内容与精确尺寸校验后才落盘；未确认请求不自动重发，也不以 HTTP 成功状态代替图片验证。
- **运行依赖打包**：修正缺失运行依赖导致的启动问题，并加入构建期依赖闭包及解包文件完整性检查；独立构建依赖与实际包检查不能替代全功能或生图验收。
- **本地 ComfyUI 工作台（桌面端）**：创作、作品库与任务记录分区，修正左右独立滚动、参数排版、弹层首帧与层级，加入适度交互动画及整体刷新。刷新重新读取服务、节点／模型、作品与任务，保留正在编辑的参数，不重启服务、不提交生图。
- **单页环境引导**：按真实状态给出一个主要下一步；仅在服务就绪且健康检查通过后提示可用。选择 ComfyUI 主目录，自动识别已知目录布局中的现有 Python；同主目录合并展示，但保留不同解释器与当前／已保存／未核验标记。显式启动时检测可用端口，不结束占用端口的其他程序；高级参数与排障默认收起。
- **Windows 独立环境安装**：可打开作者官方获取页，用户下载后导入整合包，安装到自选或默认的独立空目录，再按需创建桌面快捷方式；模型另选。macOS／Linux 仍需自行准备环境。不覆盖现有环境，不静默升级 Python、依赖、插件或模型。已知布局以外的环境可能仍须手动指定，不能保证任意第三方目录都自动匹配。
- **模型与工作流**：内置 MOSS-Image SFT、Anima Base、Krea 2 Turbo 三套直接提示词 API 起点；导入 API JSON、可证明转换的 UI JSON 及 PNG/WebP 元数据。基于实际节点定义适配参数；不能确定的动态控件或转换分支明确报告，不猜参数。已登记 116 类节点、434 项节点—输入显示映射提供五语；未知名称、枚举值、文件名和原始 ID 保持不变，不代表任意插件都可执行。
- **草稿、保存与尺寸**：重启恢复上次工作流及各流程编辑草稿，不自动启动或生成；内置流程命名另存为新库记录，自有流程保存库内原记录，均不改源 JSON／图片或图结构。保存不等于执行风险确认。内置 1024×1024、832×1216、1216×832 及用户常用尺寸，遵守真实宽高字段的类型、选项与范围。
- **任务与结果**：紧凑卡片与详情，显示最近 100 条可恢复任务摘要，不删除旧回执或原图；支持每页 12／24／48／60 条、打开结果位置及复用实际保存参数。显示队列、采样与节点进度；只取消所属任务，断线查询原任务，不自动重发。重启后未完成任务标为结果未知；缺失的历史参数不拿当前表单补写。记录独立保存，不覆盖 NovelAI 账号或历史。
- **启动边界**：仅监听本机回环，不自动打开网页；可按实际端口主动打开 ComfyUI 网页。安全模式默认关闭，可显式启用以禁用第三方节点；第三方工作流仍需独立确认，云端 API 节点禁止提交。启动不继承账号密钥，不运行第三方启动器；停止／取消启动只处理本软件持有的进程，不中断活跃任务或外部服务。MCP 客户端版本标识同步应用版本。

**反馈状态**：此前第三方中转画风迭代的 HTTP 401 问题，维护者现已报告解决；本轮未追加独立复测，不将其归因为本次源码修复。
