# 发行说明

## Latest — 手机端：结果预览与角色正面预设

- 翻看生成结果只改变预览，不会开启图生图，也不会替换手动选择的底图。要使用底图，请通过导入图片选择「图生图」，或在图库中设为工作台底图。
- 在角色卡点开「正面预设」后，点选单角色条目即可应用到当前角色；保留负面词和位置。角色卡显示应用后的正面提示词。
