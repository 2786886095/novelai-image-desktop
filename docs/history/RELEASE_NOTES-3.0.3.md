# 发行说明

## Latest — 灵感胶囊：按小类浏览，搜索整个词库

- 桌面与手机默认按两级精选分类浏览。输入关键词时搜索所选语言的完整词库；清空搜索后回到原来的小类。
- 可展开整个小类，也可以改用全库浏览，保留排序、跳页和相关推荐。全库入口区分词包总量和当前分类的数量。
- 桌面搜索框聚焦时只显示一圈边框。
