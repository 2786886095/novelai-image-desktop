### 功能变更


- 桌面、Android、iOS均加入日式漫画生成器、图片／漫画转换目标、AI推荐页数与手动页数。整页及单分镜统一一行一页，1–30页；每批最多4整页／8单格，显式续批、确认导入，不自动生图或重试收费请求。
- 六份图片新版技能原稿、日式整页v4.1及单分镜v1.0完整接入；内置只读，支持命名另存、TXT/MD/JSON导入、自定义编辑和JSON导出。旧版与自定义原文保留；版本由用户显式选用，不静默升级。
- 手机与桌面模板库均接入备份恢复；项目、队列及转换／漫画草稿独立保存。损坏文件保留并阻止请求，不默默回退内置；取消只归属本请求，过期配置／凭据或脏编辑不覆盖，截断回复保留原文且不自动重发。
- 修复模板库右上操作受弹窗关闭按钮30×30样式误命中，按内容宽度换行整颗按钮。模型、画风、负面与收费配置不由模板文本自动改变。
- 修复移动端本地 MCP 服务启停期间的地址读取竞态；服务未就绪或正在停止时不显示／复制连接信息，过期的复制与审批控件不会读取旧连接或重复执行操作。已有鉴权、人工审批、预算和不重放约束保持不变。
- 本地 Agent 组件和画风自动迭代仍仅 Windows；其他平台原本不支持的项目不因豁免而启用，也不计作验收通过。已实现的漫画／模板功能不等于所有路径均完成原生验证。
- Linux 安装包构建基线为 Ubuntu 24.04 LTS（x86_64）。本次豁免发行未完成同源完整 Linux 原生运行验收，不以构建成功、runner 标签或 WSL 检查代替。Ubuntu 26.04 已观察到 Sharp／Electron 图像运行时卡住，当前不支持；其他发行版尚未验收，未声称 Ubuntu 26.04 问题已修复。
- 回环合成服务和制品字节检查不证明远端模型画质、真实生图成功或实际扣费；本次豁免不会改变鉴权、人工审批、收费确认及已有不重放约束。
