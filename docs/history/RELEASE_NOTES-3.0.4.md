# 发行说明

## v3.0.4 — 桌面 MCP：批量整理画风，单独挂载工作台参考图

- 可查询和创建画风分组、批量移动预设，或给多个预设分配封面和示例图。批量写入前先预览，已变化的预览需重新确认。
- 封面和示例图只作展示。只有明确指定氛围迁移或精准参考时才会挂载到工作台，可回读和单独卸载。不替换底图、不切换模型，也不会因此发起生图。
- 这八个工具属于桌面 MCP；没有在手机端新增 MCP 服务。[工具与调用示例](./MCP_GALLERY_AND_PROMPTS.md)
