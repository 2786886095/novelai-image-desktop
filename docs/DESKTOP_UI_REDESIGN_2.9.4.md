# Windows 客户端界面重做（v2.9.4 候选，QQ 风格）

> 版本号沿用 2.9.4，仅本地候选构建，未发布 Release、未打标签。分支：`codex/desktop-ui-redesign-2.9.4`。
> 只改 Windows 桌面渲染层与外壳；账号、预设、图库数据、备份格式、生成参数、扣费估价、取消、重试与 MCP 逻辑均未改动。

## 设计方向

- 参照 QQ NT 桌面版：浅灰底（#F2F3F5）+ 白色卡片 + 单一 QQ 蓝（#0099FF），细线边框，8/12 px 圆角，几乎无阴影。
- 去掉“AI 味”：紫色渐变、光晕层、毛玻璃、装饰光球全部压平（101 处装饰渐变、63 个光晕层、41 处毛玻璃）；功能性渐变（进度、棋盘格、网格线）保留。
- 深色模式改为中性灰（#1A1A1A / #262626），偏紫的硬编码暗色统一中性化。
- 结构：单行标题栏 + 左侧分组导航，替代原「标题栏 + 菜单栏 + 标签栏」三层（顶部节省约 90 px）。

| 新手引导 | 首次启动 | 不变；另可从 Ctrl+K「重新打开新手引导」 |
| 新布局说明 | 无 | 首次显示可关闭的说明条，内含新旧入口对照；之后可从 Ctrl+K 再次打开 |

## 其他修正

- 两处「移除收藏」（画师串抽卡、V4.5 画师串修复器）会同时删除历史图片，原先没有确认，现已加二次确认。
- 小窗口（< 1360 px）：历史栏改为可开合的抽屉，不再在 1200 px 以下直接消失；停靠面板在 1280 px 以下浮在画布上。
- 设置页打开时隐藏底层工作区，避免浮动控件透出。

## 验收环境

隔离配置（`NAI_UI_CAPTURE_USER_DATA`，并把「图片/文档/桌面/下载」重定向进沙盒）、本地 HTTPS 假中转（仅信任测试证书）、示例图片；未读取真实密钥，未产生生图费用，未改动现有安装与用户数据。
