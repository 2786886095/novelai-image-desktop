# 本地 ComfyUI 工具

桌面端入口：**工具 → 本地 ComfyUI**。这是本机 ComfyUI 的独立客户端，不经过 NovelAI 生图接口，不要求配置 NovelAI 账号，也不会把 NovelAI Token 交给 ComfyUI。

## 连接自己的环境

1. 选择包含 `main.py` 的 ComfyUI 目录，也可选择其便携版上级目录。
2. 检查自动识别的 Python；有多个环境时，用“选择 Python”指定实际可运行此 ComfyUI 的解释器。不要选择启动器、批处理文件或系统商店的 Python 占位程序。
3. 选择结果保存目录；默认使用软件的输出目录，在其下独立保存 `ComfyUI/日期/`。
4. 点击“启动本地 ComfyUI”。界面会显示检测端口、启动中、等待 HTTP 就绪、启动完成或具体失败原因。创建了 Python 进程不等于启动完成。

启动直接调用 Python 和 `main.py`，不执行第三方启动器，不开启网页；监听固定为本机回环地址，并强制 `--disable-auto-launch`。环境检查不会自动升级已有 Python、PyTorch、插件或模型。

已有手动启动的 ComfyUI 时，填写本机地址、端口后使用“连接已有实例”。“断开连接”不结束外部进程。“停止本软件启动的服务”和退出清理只针对软件在本次会话中实际创建并持有的进程树，不按进程名称、历史 PID 或端口盲目结束程序。

## 模型与工作流

内置三套可修改的 API 工作流起点：

| 家族 | 起点 | 特别说明 |
| --- | --- | --- |
| MOSS-Image | SFT，`EmptyFlux2LatentImage` | 直接提示词；不启用可选提示词增强、SLG |
| Anima | Base v1，独立正负条件 | 按该模型的官方架构使用 `stable_diffusion` 编码器类型 |
| Krea 2 | Turbo，负条件取 `ConditioningZeroOut(positive)` | 直接提示词；不启用可选增强、LoRA；不提供无效的独立负面文本框 |

它们是按架构编写的分支明确的 API 配方，**不是完整官方 UI 模板的全部默认功能**。参考的是 Comfy-Org 工作流模板，来源和固定提交保存在各起点的本地来源记录中。没有宣称与官方前端导出的图逐字一致。

模型文件名只是起始建议。扩散模型、文本编码器、VAE 分别从实际 `/object_info` 返回的本机选项中选择；支持子目录文件名，不会根据相似名字自动替换。缺节点、缺模型、错误的枚举值会给出定位信息，修正后点击“重新分析”。真正的可用性以当前 ComfyUI 节点及其模型架构为准，家族标签不等于兼容性证明。

可导入 JSON，或包含 ComfyUI 元数据的原始 PNG/WebP；也可粘贴 JSON。图片同时含 API `prompt` 和 UI `workflow` 时优先使用记录的 API prompt。

- **API 格式**：直接分析实际执行图，保留原节点和连线。
- **UI 格式**：按当前节点定义转换并展示逐节点转换报告，未经官方前端导出对照的转换必须由用户确认。已知的子图、基础控件、重路由及确定的布尔分支可转换；无法证明的动态控件、缺失的命名值、未知模式会明确阻止提交，而不是猜参数或悄悄删除。
- 复杂图无法转换时，请在 ComfyUI 中导出 **API 格式**再导入。未修复的阻断项不会发出生图请求。

可调控件绑定到实际节点的具体输入。分支改变后，界面会列出失效参数，只有用户确认清理才移除它们，其余输入保留。

## 安全与结果

默认安全模式禁用第三方节点；需要插件图时可显式关闭，但插件本质上是用户安装的 Python 代码，可能自行访问网络或启动程序，宿主无法承诺任意插件的行为。第三方执行节点另需确认，工作流或节点目录发生相关变化后确认会失效。云端 API 节点在此本地工具中禁止提交。

额外参数每行一个词，选项和值分别一行，路径不加引号；主进程只接受安全白名单，不执行 shell。启动进程不继承账号密钥和代理环境变量。

任务通过本机 HTTP/WebSocket 提交。断线后查询同一 prompt 的历史，不自动再次提交。取消只针对能核实属于本任务的队列项或当前运行项，不清空别人的队列。结果按真实历史状态及图片内容校验后保存；队列清空不代表生图成功。

结果、工作流和配置保存在独立的 ComfyUI 记录中，不插入或清空 NovelAI 历史。可以查看图片、打开结果位置、复用参数或以相同参数再次生成。随机模式记录实际使用的种子；固定参数复用保留能静态确认的原始连线。

## 平台与验收范围

本机启动属于桌面功能。Windows、macOS、Linux 均需用户准备对应的 Python/ComfyUI 环境；实际兼容性取决于环境和模型，不能把 Windows 的实机结果当成其他系统的验收。Android/iOS 没有本机启动 Python 的此入口，也不会隐式把参考图转发到其他电脑。

本轮总体方案和共享接口契约由 Claude CLI 的 `claude-opus-5-5` 制定。其后 CLI 达到周额度上限，后续实现、集成和验收依据已保存的方案由执行团队完成；未把这些后续代码冒称为该 CLI 已完成。
