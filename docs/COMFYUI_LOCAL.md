# 本地 ComfyUI 工具

桌面端入口：**工具 → 本地 ComfyUI**。这是本机 ComfyUI 的独立客户端，不经过 NovelAI 生图接口，不要求配置 NovelAI 账号，也不会把 NovelAI Token 交给 ComfyUI。工作台以参数创作、作品库和任务记录为主，不是完整的拖拽节点编辑器。

## 连接自己的环境

环境设置采用单页引导：先看当前状态和主要下一步，进阶参数、排障和其他环境按需展开。检测到 Python 或创建了进程都不等于已可生图；只有服务就绪并通过健康检查后才显示可用，模型与节点仍需按具体工作流检查。

1. **选择主目录**：选择包含 `main.py` 的 ComfyUI 目录，或已知便携布局中包含 `ComfyUI/main.py` 的上级目录。不必先填 Python 路径、端口或额外启动参数。
2. **确认现有解释器**：对已知的 `python_embeded`／`python_embedded`、绘世 `python`／`.ext`、`.venv`／`venv` 布局进行有界检测，优先使用同环境中已确认兼容的解释器，不安装或升级依赖。它不是任意系统 PATH、Conda 或第三方目录的通用解析器；无法判断时会说明原因并允许高级手动选择。
3. **多个 Python 不混为一个**：扫描按规范化主目录合并为卡片，所有不同解释器路径及参数仍是独立选项，并显示当前使用、已保存或尚未核验。静态扫描不执行 Python；对其他候选执行检测前需要明确同意。检测信息通过也不代表已装好模型。
4. **启动或连接**：点击“启动本地 ComfyUI”后检查实际可用端口，显示探测、启动、就绪或具体失败原因。选主目录会使用自动端口；专家手动设置可在高级项中保留。占用端口的其他程序不会被结束。已手动启动的服务可通过“连接已有实例”指定实际本机端口。
5. **结果目录与网页**：默认在软件输出目录下保存 `ComfyUI/日期/`，也可自选。服务就绪后，可明确点击“打开 ComfyUI 网页”，使用当前服务实际端口；不会自动打开浏览器。

启动直接调用现有 Python 和 `main.py`，不执行第三方启动器；监听固定为本机回环，并强制 `--disable-auto-launch`。环境检查不会自动升级 Python、PyTorch、插件或模型。

“断开连接”不结束外部进程。“停止本软件启动的服务”和退出清理只针对本次会话实际创建并持有的进程树，不按进程名称、历史 PID 或端口盲目结束程序。有活跃工作台任务时先完成或取消任务，不用停止服务代替取消；取消尚在启动的本软件服务也不会中断外部任务。

## 没有 ComfyUI 时（Windows 托管安装）

Windows 可从环境页打开作者官方获取页，自行下载完整整合包，再回到软件选择整包导入。安装到自选或默认的**独立空目录**，环境和模型不放进应用更新覆盖范围；检测到非空目录不会覆盖。安装完成后可按需创建桌面绘世启动器快捷方式，不覆盖已有快捷方式；模型由用户另选。软件不会悄悄下载整合包、替换既有环境，或在选择目录时安装／升级依赖。macOS／Linux 暂不支持这项托管整合包安装，仍可自行准备并选择现有环境。

## 模型与工作流

内置三套可修改的 API 工作流起点：

| 家族 | 起点 | 特别说明 |
| --- | --- | --- |
| MOSS-Image | SFT，`EmptyFlux2LatentImage` | 直接提示词；不启用可选提示词增强、SLG |
| Anima | Base v1，独立正负条件 | 按该模型的官方架构使用 `stable_diffusion` 编码器类型 |
| Krea 2 | Turbo，负条件取 `ConditioningZeroOut(positive)` | 直接提示词；不启用可选增强、LoRA；不提供无效的独立负面文本框 |

它们是按架构编写的分支明确的 API 配方，**不是完整官方 UI 模板的全部默认功能**。参考的是 Comfy-Org 工作流模板，来源和固定提交保存在各起点的本地来源记录中。没有宣称与官方前端导出的图逐字一致。

模型文件名只是起始建议。扩散模型、文本编码器、VAE 分别从实际 `/object_info` 返回的本机选项中选择；支持子目录文件名，不会根据相似名字自动替换。缺节点、缺模型、错误枚举值会给出定位信息，修正后可重新分析。真正的可用性取决于当前 ComfyUI 节点及模型架构，家族标签不等于兼容性证明。

可导入 JSON，或包含 ComfyUI 元数据的原始 PNG/WebP；也可粘贴 JSON。图片同时含 API `prompt` 和 UI `workflow` 时优先使用记录的 API prompt。

- **API 格式**：分析实际执行图，保留原节点和连线。
- **UI 格式**：按当前节点定义转换并展示逐节点转换报告；未经官方前端导出对照的转换必须由用户确认。已知子图、基础控件、重路由及确定的布尔分支可转换；无法证明的动态控件、缺失命名值、未知模式会明确报告并按执行相关性阻止提交，不猜参数或悄悄删除。
- 复杂图无法转换时，请在 ComfyUI 中导出 **API 格式**再导入。未修复的阻断项不会发出生图请求。

可调控件绑定到实际节点的具体输入。通用适配依据当前服务的字段类型、范围和枚举定义，不等于支持所有自定义节点。分支改变后会列出失效参数，只有用户确认清理才移除，其余输入保留。参数分析需要已连接的服务提供当前节点目录；离线保存和恢复的草稿不冒充最新分析，提交前仍须通过当前模式校验。

### 草稿、保存与常用尺寸

- 重启后恢复上次工作流、各工作流的编辑值与种子模式，但不会自动启动服务、恢复队列或提交生图。
- **内置流程**仅能命名“另存为”新库记录；**自有流程**可保存至同一库记录，也可命名另存。保存只更新库内参数快照，不覆盖导入的源 JSON／图片，不改图结构、连线或原始节点 ID。保存成功不等于确认第三方执行／UI 转换风险。
- 默认尺寸包含 **1024×1024、832×1216、1216×832**，可新增本机常用尺寸。仅当工作流存在对应宽高字段且数值满足各自类型、选项与范围时应用；不会硬加不存在的字段。步长用于界面增减，不作为额外的整除限制。
- 节点与字段的五语显示覆盖 **116 类已登记节点、434 项节点—输入映射**，采用 279 行显示词条。未知节点、用户标题、提示词、文件名、枚举 token 和原始 ID 保持原文，显示翻译不改提交值。

## 任务、作品与刷新

任务通过本机 HTTP/WebSocket 提交。紧凑卡片提供任务状态与详情，显示可核实的队列、采样和节点进度；列表显示最近 **100 条**可恢复摘要，不删除旧回执或原图，可选择每页 **12／24／48／60 条**。详情仅展示实际保存的时间、错误、参数与图片；没有记录的字段显示未知，失败或无图历史不会拿当前表单冒充旧参数。服务运行日志不是完整的逐任务日志存档。

断线后查询同一 prompt 的历史，不自动重复提交。重启后原先未完成的任务按结果未知处理，不自动重放。取消只针对可核实属于本任务的队列项或当前运行项，不清空别人的队列；队列清空也不代表生成成功。结果按真实历史状态及图片内容校验后保存。

创作页支持查看当前图与会话预览；作品库与任务记录分页浏览，可打开结果目录、在文件夹中显示已知文件、复制路径和复用实际参数。随机模式记录实际使用的种子。结果、工作流和配置独立保存，不插入或清空 NovelAI 历史。

**整体刷新**重新读取服务状态、节点／模型清单、作品和任务，保留正在编辑的值；不重启服务、不提交生成、不将刷新失败当成任务成功。左右内容区独立滚动，弹层在独立层级展示。

## 安全边界

安全模式**默认关闭**；需要限制第三方节点时可在高级设置显式启用（取决于环境支持的启动选项）。既有已保存设置不会被无条件覆盖。第三方执行节点仍需单独确认，工作流或节点目录发生相关变化后确认失效；保存草稿／流程不会持久化这项执行授权。云端 API 节点在本地工具中禁止提交。

插件本质上是用户安装的 Python 代码，可能自行访问网络或启动程序，宿主无法保证任意插件的行为。额外参数属于高级选项，使用安全白名单，每行一个词，选项和值分行，路径不加引号；主进程不执行 shell。启动不继承账号密钥和代理环境变量。

## 平台与验收范围

本机启动属于桌面功能。Windows、macOS、Linux 均需对应的 Python/ComfyUI 与模型；软件只识别已知布局，不能保证任意环境自动匹配。Android/iOS 没有本机启动 Python 的入口，也不会隐式把参考图转发到其他电脑。

此前已在 Windows 本机用 MOSS-Image SFT、Anima Base、Krea 2 Turbo 实际生成并核对结果，以及验证启动／停止／重启。最新工作台、引导、翻译、保存与草稿改动经过隔离的单元／浏览器回归，未新增真实用户环境或 GPU 生图验收；macOS／Linux 模型推理尚未实机验收。任意插件和任意工作流不在此保证范围。

正式功能验收以本次发布流水线提供并绑定实际制品的证据为准，本地候选回归不等于五端功能验收完成。现有发行功能门是 Windows／macOS／Linux／Android 的 153 项要求；iOS 为附加未签名 IPA 打包，不等于 iOS 功能验收。需自行签名，不能直接安装到普通 iPhone。完整制品、签名、校验与平台限制以 [Latest](https://github.com/2786886095/novelai-image-desktop/releases/latest) 的实际证据为准。

早期总体方案和共享接口契约由 Claude CLI 的 `claude-opus-5-5` 制定；当时 CLI 达到周额度后，后续实现、集成和验收依据已保存方案由执行团队完成，未把这些代码冒称为 CLI 已完成。策划记录不代替功能验收。
