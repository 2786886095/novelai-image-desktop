# Desktop and mobile: image metadata, NAX directory, and offline tags

- Image metadata tools outputs newly encoded static PNGs in a ZIP. Inputs are static PNG/WebP, capped at 64 MiB / 16 megapixels per image and 64 images per batch. Animated and unsupported formats are rejected. The tool removes container metadata and known alpha/RGB stealth metadata, not arbitrary steganography. Re-encoding can change colors/precision/alpha slightly; originals are not overwritten. NovelAI and SD WebUI/Forge edits are written as standard PNG international text fields. Editing does not create an official signature. ComfyUI workflow editing is not implemented.
- NovelAI defaults to the existing official online reader (scripts are fetched; images stay local). Failures do not silently switch to local. SD parameter reading is local. Batch writes are an explicit desktop UI action; no unrestricted MCP filesystem tool was added.
- NAX is an attributed directory of 15 public experiment collections. Images and interactions stay on the source site; no native image mirror.
- The selected offline pack replaces ordinary autocomplete and local MCP tag searches; exact and prefix lookups use the original tag or chosen translation and show usage counts. Related tags and artist catalogs are separate. The first-run guide and existing settings use the same pack selector. The MCP search_tags call never uses a paid/concept API.
- To produce separately distributed packs, run scripts/build-multilingual-tag-packs.py against the complete non-artist source CSV, passing the source snapshot date as the fourth argument. Include all four gzip files when hosting the data. Users choose a language in the app and download it directly; no manual import is required. Both compressed and decompressed content is verified before activation. Verify upstream terms before redistributing the user-provided data.
- The 2026-11-26 data release contains 510,583 rows per language. Its four gzip files are data, not installers. Both clients pin their checksums and the release asset IDs; changing the manifest also requires rebuilding the matching browse previews and row-ID index.
- On desktop, public tag downloads honor system-trusted certificate issuers (including a trusted HTTPS-inspection proxy). Invalid or untrusted certificates still fail; do not disable certificate validation.
