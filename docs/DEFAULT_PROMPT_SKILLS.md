# 默认提示词技能：1.0.0 / 2.0.0

模板版本与目标生图模型是两个独立选项，不是 AI 接口服务的模型名称。

- **1.0.0**：本轮接入前的有效默认规则与原有用户自定义槽位，保留 V4.5 / V5 选择。
- **2.0.0**：用户提供的六份独立 Markdown 原稿（图片反推、文字转换 × 纯 Tag、纯自然语言、混合）。`shared/prompt-skill-catalog.json` 保留完整正文、原文件名与逐份 SHA-256。没有把纯模式从混合稿重新派生，也没有拼接六篇。
- 新原稿明确面向 **NovelAI V5 Full**。选择 V4.5 时使用 1.0.0，并显示兼容提示；没有把 V5 专用语法简单改名后冒称适配。模型选择只决定提示词规则，不自行改变生图参数。
- 无旧自定义的新配置使用 V5 / 2.0.0；真正已有的自定义内容保留在 1.0.0。新旧版本自定义槽位分离，恢复默认只作用于当前槽位。

## 四个入口

| 入口 | 基础正文 | 编辑规则 |
| --- | --- | --- |
| 图片反推 | 对应版本、目标模型和模式的反推模板 | 只围绕本次图片和指定范围 |
| 文字转换 | 对应版本、目标模型和模式的转换模板 | 只转换明确输入 |
| 提示词助手 | 所选版本和模式的转换模板 | 独立助手编辑覆盖规则；只落实本次修改 |
| 提示词优化 | 所选版本和模式的转换模板 | 独立优化覆盖规则；保留事实，不为计数编造 |

助手与优化共享自己的版本、规则模型和模式选择，不借用 AI 接口模型字段。
原有导入的系统提示词预设是另一层；本轮不会清空或替换它们。

## 其它反推／转换位置

主反推、主转换之外，重绘内联反推、画风实验室、Artist Detective、漫画批量反推与通用提示词助手／优化都提供模板版本与目标生图模型选择。内联反推与主反推共用已保存的偏好，助手／优化使用自己的独立偏好；选择模型不会更改 AI 接口模型或当前生图参数。

异步返回按发起时的上下文保留到任务记录，配置或输入已变化时不覆盖当前内容。

## 输出与检查边界

2.0.0 保留原稿单行输出，普通模式不套旧的 50–150 单元 JSON 协议；网络角色双版本选项仍使用两个字符串字段承载各自单行结果。明确的“信息不足”“模式能力不足”、拒答或无效格式不会作为成功提示词覆盖原文，也不会自动要求补足编造。

可确定的 Tag 数量没有旧的 150 上限；混合比例按英文词数而非逗号单元数。句子里的逗号不用于膨胀计数。自然语言的来源事实数量、准确性和同义概念无法仅靠语法程序严格证明，成功提示会说明仍需人工复核，不将基本格式检查称为语义质量保证。

正文中的检索规则不是工具授权。普通 AI 接口调用没有外部检索工具时，会明确追加真实能力说明，走原稿无工具分支，不声称查过世界书、Danbooru 或官方文档。附件的合成示例不是默认画面事实。

功能开发只修改独立候选副本，不覆盖原安装或用户数据，也不另增应用版本号。正式发布另受授权与 Windows / macOS 验收门槛约束，不能用本机测试或构建成功代替验收。
