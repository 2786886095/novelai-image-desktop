# Windows 双布局与画风迭代候选

- 基线是 v2.9.5 既有候选，而不是 GitHub v2.9.4 安装包。把独立 UI 源码提交 c9cd3fe0 以 Git 合并引入；原工作树与原 EXE 仍保留。
- 设置 → 外观 → 桌面界面布局。默认经典，选新版即时切换并记住选择。两种布局共用一个 store 和 IPC，没有复制账号、画稿、图库数据库或任务。现有 macOS、Linux 默认走经典布局。
- 元数据批处理、NAX 来源和四语词库仍沿用原生实现。四包来自用户提供的 2026-11-16 全量表；仅分发标签、使用量、分类和四语释义。首次使用时在软件内点选一个语言下载，无须手动导入。
- #89 新增独立的固定画师栏；已指定的权重不随候选变动。目录外画师冻结到本次任务的私有目录，不改已安装模型。预测器不尝试为未训练过的画师估值；实际生成与最后评分仍保留手动标签。搜索服务仍仅 NAI 4.5 Full，不冒用 V5 的参数。
- 可选本机图片目的地。新图片另存到唯一的任务子文件夹，默认仍在内部目录。原图与任务恢复日志留在内部；已有文件不会被覆盖。清理内部结果不会删除另存副本。路径由用户原生选择，MCP 不能注入任意文件路径；同样受原生扣费确认约束。
- 不发布、不覆盖旧候选。不以测试夹具代替真实付费生图或 GPU 验收。
