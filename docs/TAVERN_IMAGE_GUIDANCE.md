# 内置世界书：按生图模型选择技术原文

## 本轮有效范围

- V5（`nai-diffusion-5-*`）：9.7 V5 测试版，15 个技术条目。
- V4.5（`nai-diffusion-4-5-*`，含 Full/Curated）：8.31，15 个技术条目。
- 其他或未确定模型：不猜测版本、不注入上述条目。
- 两端使用 `shared/tavern-image-guidance.json` 的同一内容；Flutter 镜像由 `node scripts/sync-tavern-image-guidance.mjs` 生成，`--check` 检查一致性。

## 运行适配与边界

1. 原文存储与请求渲染分开：只在当前请求、当前世界书内展开 `setvar/getvar`；支持前向引用，已知变量条目被用户关闭时其展开为空，不从其他书或旧请求借值。未知变量和循环引用明确报错，不执行脚本。
2. 内置世界书预算从 4096 调整为 16384，以容纳整套技术原文，避免旧预算只加载其中一部分。实际上下文仍占用所选对话模型的窗口，不声称与精简版等长或等快。
3. 在系统提示末尾追加独立、双端共用的运行适配契约；不改写技术正文。模型输出仍须遵循本软件的 `langbai-image`、`scene/scenePatch/promptPatch` 契约。此轮没有另行实现第三方插件 `image###` 通用解析器，也没有安装该插件。
4. 原文多图配额、附加图像、UC 和默认尺寸不覆盖右侧权威参数；空负面/风格仍为空，局部修改不授权整段删除角色记忆。
5. 内置世界书 ID 保持不变，已有会话重新加载时会更新内置条目；用户自建世界书、角色生图设置和已有条目启用开关保留。切换生图模型会重新选择匹配版本。
6. 作用域仅为绑定该内置世界书的酒馆会话，不向转换、反推或其他模块自动扩散。

## 验证口径

原文件核对、双端自动测试、类型检查与构建的命令及结果见本轮验证记录。不把单元测试称为真实模型生成质量验证；此轮未发起付费模型/图像请求，也未发布新版。
