# 画师比较与画师组合探索

在桌面端打开「工具 → 画师比较与组合探索」。这个功能把每个项目保存为独立的本地长期资产，用相同的生成条件比较单画师和画师组合，并保存图片、评级、标签、备注、封面和生成记录。

## 先理解三个概念

- **项目**是相互独立的长期库。项目有自己的对象、评级方案、标签、备注、图片和生成历史。两个项目可以出现同一个画师，但彼此不共享数据。发现新画师、修改探索规则或跨日期继续工作时，继续使用原项目即可，不需要为了这些事情新建项目。
- **单画师**是一个不含逗号的画师提示词。**画师组合**（代码中也称配方）是一个含逗号的提示词。
- **生成记录**是某次批量任务的历史记录，保存当时的对象、共同提示词、模型参数和种子快照。生成记录会留在项目中，方便比较不同日期的结果；项目是长期库，生成记录是其中的历史批次。

## 新建项目和加入对象

1. 新建或选择一个项目。
2. 选择「普通文本」，每行粘贴一个对象，然后点击「加入项目」。
3. 如果从 Excel、WPS 或其他表格复制多列，选择「TSV / Excel」，把剪贴板中的表格文本粘贴进去，再把列映射为名称、提示词和备注，最后点击「加入项目」。这里支持的是表格单元格复制出来的 TSV 文本，并不是直接打开或导入 .xlsx 文件。图文表格导出的格式是 .xlsx；要恢复完整项目，需要使用完整备份 ZIP。

### 如何判断单画师和画师组合

程序按提示词列的实际文本判断：

- 每个非空物理行或 TSV 行是一个对象。提示词中嵌入换行时，解析器会把它视为新的物理行。
- 提示词中出现英文逗号或中文逗号，就把这一行当作一个画师组合。逗号属于当前画师串，不是分隔多行的符号。
- 分号、括号、反斜杠括号和其他标点，在没有逗号时都属于画师名本身。因此，不能用括号或分号来判断组合。
- 可以使用可选的 artist: 前缀。TSV 的名称列只是显示名称，提示词列才是发送给生成接口的画师提示词。

下面是一组完全虚构的示例：

~~~text
demo_artist_a
demo_artist_b
demo_artist_c
demo_artist_a, demo_artist_b
~~~

前 3 行是单画师，最后 1 行是一个画师组合。可以给它们设置一个安全、通用且不含人物的共同正面提示词：

~~~text
wide cinematic landscape, mountain lake, pine forest, sunrise, soft light, detailed background, no people
~~~

demo_artist_a 等名字只是文档示例，不是真实画师；示例也不承诺模型会识别这些名字。

### 加入时如何去重

「加入项目」会对**单画师**做精确规范化去重：

- 会在当前项目中查重，也会在本次粘贴内容内部查重。
- 会去掉首尾空格和开头的 artist:，忽略大小写，把连续空格和下划线视为等价，并处理转义括号。
- 这是精确匹配，不是模糊匹配。相近但不同的名字不会被猜测成同一个画师。
- 画师组合不会因为看起来相同而自动合并；其他项目中的同名对象也不会被跳过。
- 去重不会删除已有对象、图片、评级、标签或备注。

本次真正加入的新对象会按照粘贴顺序插入项目最前面，并自动选中。因此持续补充长期项目时，按下面的顺序操作：

1. 粘贴新画师，点击「加入项目」。
2. 检查新卡片是否在最前面且已经选中。
3. 点击「生成新增画师」。

如果粘贴的对象全部重复，界面会报告跳过了重复对象；确认没有新增后，就不需要再点击「生成新增画师」。如果之后手动清空选择，生成按钮可能会选择当前类型中尚未安排过的对象，因此点击前请先检查选择状态。

## 共同条件和批量生成

在「共同条件」中设置共同正面提示词、共同负面提示词、模型、宽度、高度、步数、CFG 和 1–10 个种子。每个选中的对象使用同一组种子，便于横向比较。

点击生成后，软件会先报价并要求确认。这里的报价只是待生成任务的 NovelAI Anlas 预估消耗，不是拍卖报价或竞价。确认的额度是本次排队的预算边界；软件在提交每张图前会再次检查费用，预算不足就停止继续提交。账户余额、模型权限和官方实际扣费以 NovelAI 为准。

每个内部生成段最多包含 5,000 个任务（对象数 × 种子数），单次最多使用 10 个共同种子。超过这个数量时，软件会自动拆成多个保存下来的生成段，使用相同的参数快照并按顺序继续。这是单次操作的队列限制，项目中的单画师总数和组合总数没有共享的 5,000 条上限。

## 新增画师后继续旧任务

项目库负责长期保存对象，生成记录负责保存任务进度。例如旧任务已经完成一部分时，可以：

1. 先点击「暂停排队」，让当前图片完成后停止安排下一张。
2. 加入新画师。新增对象会排在最前面并自动选中。
3. 点击「生成新增画师」，只为选中的新对象创建任务。
4. 新任务完成后，点击「继续原任务」。

「继续原任务」会找到最早仍有待生成任务的生成段，跳过已经完成或重复跳过的任务，继续使用旧任务的共同提示词、模型和种子。已经完成的图片不会因为加入新画师而重跑。已经有生成记录的对象也不会被「生成新增画师」再次安排；想只为某一张卡片取得新图时，应使用卡片内的单卡重生成。

如果程序重启时某个请求处于进行中，软件会先在本机生成历史中寻找对应输出。找到输出就恢复为已完成；无法确定结果时会标记为「待核对」（uncertain），必须明确确认风险后才能重试。网络可能在服务已经接受付费请求后才中断，因此这个确认是实际的扣费风险边界，不能承诺网络层面的绝对只执行一次。

## 评级、标签、封面和单卡重生成

评级方案可以自定义名称、颜色和顺序。单画师一旦评级，就会自动进入对应评级的探索池；未评级的单画师不会入池。手动粘贴的组合和探索生成的组合即使被评级，也永远不会进入单画师池，但仍可以继续评级、加标签和写备注。

当前评级方案会按稳定的评级 ID 同步到历史生成记录。删除已经使用的评级档位时，必须明确映射到其他档位或清空相关评级。旧记录中如果存在已经删除的评级方案，界面会显示映射面板；相同的文字名称不会被程序擅自当作同一个档位。

每个项目有自己的标签目录。一个对象可以选择多个标签，并按标签筛选。标签和备注是整理信息，不会被追加到生图提示词。

新生成段的第一张成功图片可以成为该卡片的封面。可以从已保存图片中选择其他封面，也可以移除封面标记；移除封面不会删除原图或生成历史。卡片内的「仅重生成此卡片 · 1 张」会使用当前共同条件和新的随机种子，重新报价后只创建一个任务。旧图片仍保留；如果重生成失败，原封面、评级、标签和备注也会保留。

## 探索画师组合

在同一个项目中切换到「探索画师组合」。这里使用「单画师比较」中已经评级的单画师池，今天和以后生成的组合都会持续累积在当前项目中，方便统一对比；不同项目仍然完全分开。

针对每个评级档位，可以设置抽取数量、最小权重和最大权重，再设置要预览的组合数量以及独立的组合随机种子。当前界面支持预览 1–100 个候选组合；它只生成有限候选，不会穷举所有排列。每个组合内部会按规范化后的画师身份无放回抽取；如果某个池没有足够的不同画师，程序会报告池子不足，不会悄悄重复同一画师。

预览后检查组合，选中需要生图的卡片，点击「生成未安排的对象」。组合会成为普通的组合卡片，可以生图、评级、加标签和备注，但不会反向进入单画师探索池。

## 生成间隔、暂停和限流边界

每个项目都有最短和最长生图间隔，默认都是 30 秒：

- 范围是 0–3600 秒，精度为 0.1 秒。
- 例如设置 30–60 秒，每张图片完成后会独立抽取下一次等待时间；两个端点相同就是固定间隔；两端都为 0 表示不额外等待。
- 修改间隔会在下一张图片完成后生效；暂停再继续时，已经抽取的等待截止时间会保留。
- 随机间隔只是排队节奏设置，不保证绕过 NovelAI 的限流、风控或服务端限制。

批量队列由桌面端主进程管理，因此渲染页面刷新不会直接丢弃队列，也不会让多个比较任务并行占用同一生成通道。本功能目前只提供桌面端比较界面，移动端没有对应页面。

## 导出、备份和本地存储

在「导入与导出」区域有 3 种用途不同的格式：

- **导出表格 CSV**：适合纯文本筛选和交换，包含当前库及历史生成记录中的对象类型、提示词、评级、标签、备注、种子、状态和封面信息，但不内嵌图片。
- **图文表格 Excel**：.xlsx 中分别提供单画师、画师组合、生成条件和说明工作表，包含评级、标签、备注、提示词和保存下来的生成参数。每个对象嵌入一张预览图，优先使用选定封面，否则使用最近成功图片。预览图会转换为 JPEG，质量 78，最长边不超过 480 像素，按照原图比例缩放，不裁切、不拉伸、不放大。它适合阅读、查找和筛选，不等同于原图全集，也不能替代可恢复的任务备份。
- **完整备份 ZIP**：保存项目清单、CSV、所有被引用的原始 PNG、相对路径和 SHA-256 校验值，包含对象、生成记录、任务进度、评级、标签、备注、封面和间隔设置。导入会先校验压缩包，并创建一个新的独立项目，不覆盖已有项目。ZIP 不包含 API Token 或账号设置。

桌面端还可以进行文件级备份。比较元数据位于应用用户数据目录下的 artist-comparison/；现在的格式使用 projects.v1.json 作为索引，并在同级 projects.v1.json.parts/ 目录中保存项目和生成记录分片。关闭应用后请复制整个 artist-comparison/ 目录，不能只复制索引文件。这个目录包含导入的图片，但比较任务生成的图片可能位于应用通常的历史记录或输出目录；如果要做完整的文件级恢复，还需要一起复制相关的原图目录。更稳妥的可移植方式是使用「完整备份 ZIP」。写入失败时会保留之前已经提交的状态。

当前安全限制包括：ZIP 文件及展开内容最大 2 GiB，清单最大 32 MiB，单张图片最大 64 MiB，项目数量最多 50 个。渲染器仍需把项目元数据载入内存，因此这些是安全边界，不是无限容量承诺。

## 隐私和开源贡献

画师库、生成图片、私人词库、备注和 API 凭据都是本地用户数据，不属于功能源代码。提交公开分支、Issue 或 PR 时，不要上传这些内容，也不要提交本机路径、Token、私人 Excel 或真实截图。请使用 demo_artist_a 这类虚构名字、合成图片和最小化测试数据。

## 开发者检查

在桌面端项目目录运行：

~~~sh
npm run typecheck
npm test
npm run build
~~~

相关测试覆盖多行和 TSV 解析、逗号分类、规范化去重、评级映射、确定性的组合探索、组合排除出单画师池、暂停与恢复、费用预算边界、分片存储原子写入以及 ZIP 完整性和路径校验。手动测试请使用隔离的应用数据目录；不要把本地比较库或生成图片提交到仓库。
