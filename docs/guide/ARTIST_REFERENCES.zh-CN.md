# 共享画师原作参考

画师比较中的“共享原作资料”用于把画师原作与 AI 生成结果并排查看。原作封面、D 站收录数和来源链接属于本机的全局画师资料，同一画师出现在多个项目时共用。项目的生成图片、评级、标签、备注与队列仍独立保存。

## 使用

1. 打开“单画师比较”，通过评级、标签或备注筛选目标画师，也可以勾选卡片。
2. 点击“补充已选原作”或“补充当前筛选原作”；按钮显示的是这次操作的单画师数量。画师组合不参与获取。
3. 全局队列逐个获取缺失资料，已保存的封面直接复用。可以暂停、继续及重试失败。重新打开软件后队列保持暂停，由用户决定何时继续。
4. 卡片显示原作参考缩略图与收录数；打开 AI 大图后可并排查看原作。
5. “选择原作 / 绑定画师”可从候选作品中更换全局封面。匹配失败时，填写 `https://danbooru.donmai.us/artists/82182` 这样的画师页面链接或 ID。更换封面会同步到所有引用该画师的项目。

## 本地参考图

卡片上的“本地上传原作”可以选择本机图片作为共享参考封面。图片只在本机处理，不上传网络；保留原文件，另存等比例压缩预览。换图会同步到所有使用同一画师的项目。它不会改变画师的 D 站收录数，也不会改变项目的评级、标签和生成结果。原作库 ZIP 同时备份本地参考图。

## 图片与数量

- 参考图最长边 960 像素，保持比例，不裁切、不拉伸、不放大小图；保存压缩 JPEG，不把原始大图永久保留在本地。
- 参考封面保留 D 站帖子链接，可打开来源查看原作。候选预览按需加载，默认仅使用可访问的 General / Sensitive 静态作品。
- “D站收录数”是该画师标签的投稿计数，不是 NovelAI 的训练样本数量，也不能据此断定画风学习质量。收录数附查询日期。
- 默认封面来自最新可用收录；D 站上传日期不代表原作创作日期。一幅作品不一定代表画师的全部风格，建议必要时手动更换。

## 获取失败

找不到匹配、没有可用作品、访问限制及网络失败都会显示为可处理的状态，不以“0 张”冒充未知计数。失败不会覆盖已有封面。遇到站点限流会退避或暂停，避免密集重试。本功能不绕过登录、人机验证或访问权限。

本模块不提交 NovelAI 生图请求，不消耗 Anlas，也不修改 AI 生成队列。测试应使用隔离资料目录和少量公开画师；不要把个人画师库、原作缓存或账号设置提交到 GitHub。

## 备份共享原作库

“共享原作资料”中展开“原作库备份”，可导出独立 ZIP，包含全局原作封面、收录数及来源。它与项目 ZIP 分开保存；迁移机器时请同时备份两者。导入前暂停原作获取并等当前项完成；导入只添加本机尚不存在的画师资料，已有封面不会被覆盖。原作库备份不包含 API 配置、共同提示词或 AI 生成图。单份原作库备份的导入/导出保护上限为 512 MiB，不是画师数量上限。
