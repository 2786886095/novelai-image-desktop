# 功能指南

[返回项目首页](../../README.md) · [首次使用](./GETTING_STARTED.md)

以仓库 v2.2.4 的功能实现为依据。下文按创作任务组织，不将模型相关能力视为所有模型通用；具体可选项以当前模型和客户端显示为准。

<a id="generation"></a>
## 生成与修图

**入口：生成、重绘、后期。**

| 能力 | 可以做什么 |
| --- | --- |
| 文生图 | 选择模型与正 / 负面提示词，调整尺寸、Seed、Steps、CFG、采样器、UC Preset 和质量词 |
| 模型相关选项 | 在支持的模型下使用透明背景、SMEA、Variety+ 等；不是所有模型都有同一组选项 |
| 图生图 | 载入 PNG / JPG / WebP 基图，调整 Strength、Noise 与 Extra Noise Seed；尺寸可按原图适配或自定义 |
| 角色提示词与位置 | 分别编写角色描述，选择 AI 自动位置或拖动编号标记定位，也可精确调整 X / Y |
| 局部重绘 | 在蒙版画布标记需要重绘的区域，通过 NovelAI infill 修改局部 |
| 云端超分 | 使用 2x / 4x 放大；输入面积限制与预缩放行为以应用内提示为准 |
| Director Tools | 移除背景、线稿、草图、上色、表情迁移、去杂乱等后处理 |
| 成本与额度 | 查看 Anlas、生成前估算、实扣记录，以及适用账号的 V5 Opus 额度状态；过期缓存与实时状态分开显示 |

尺寸按有效的 64 倍数处理。想复现或微调一张图时，优先复用历史参数并锁定 Seed，而不是只复制正面提示词。

<a id="tavern"></a>
## 酒馆对话创作

**入口：酒馆 AI 生图。** 对话模型负责整理回复与图像方案，NovelAI 负责生成图片。

### 一个建议的开始方式

1. 配置对话模型与 NovelAI Token，选用内置生图角色或导入自己的角色卡。
2. 在右侧设置风格提示词、负面词、模型、尺寸、采样器和张数。
3. 用自然语言描述场景，先选择「确认后生图」。
4. 检查生成方案，必要时编辑参数，再确认生成。

| 模式 | 行为 |
| --- | --- |
| 确认后生图 | 先给出方案，用户可以修改后再确认调用 |
| 全自动生图 | 按方案直接调用，默认参数来自右侧创作面板 |

**参数优先级**：未明确点名的生成参数沿用右侧设置；用户明确要求的参数才覆盖对应项。风格词和负面词由右侧面板控制，风格词留空时不会继承生成页的风格。

### 对话与素材管理

- 管理角色卡、世界书、用户设定与对话预设；支持 SillyTavern 相关角色卡格式的导入 / 导出，兼容边界以实际导入结果为准，并非完整移植所有扩展。
- 角色卡可导出 PNG / JSON / CHARX；对话可新建、重命名和删除。
- 导入 JSON 预设后可以重命名或删除；同一套相关任务预设可用于酒馆、反推和转换。
- 生成图片可预览、复制与保存；大图预览可通过点击周围空白关闭。

<a id="comic"></a>
## 漫画与批量任务

**入口：工具 → 漫画生成器 / 批量重绘。**

### 漫画生成器

- 导入一行一镜的 Tag，也可导入带分镜标题的 JSON / CSV。
- 全局统一风格、负面词与生成参数；单个分镜可独立覆盖参数。
- 每个分镜一次生成 1～10 张候选图，可以继续追加尝试。
- 预览、比较并选定主图；最终 ZIP 只打包每个分镜当前选中的主图，而不是所有候选。

逐行导入可以从下面的两镜开始；这只是格式示例，不自动保证角色一致性：

```text
1girl, solo, blue hair, garden, standing, morning
1girl, solo, blue hair, garden, sitting on bench, afternoon
```

如果要保持角色和画风连贯，配合全局风格、角色描述与参考预设一起使用。

### 队列与重绘

生成队列支持暂停、继续、失败重试或跳过，并记录实扣 Anlas。批量重绘适合成组处理已有图片；开始前检查每个任务的输入、参数和预期费用。漫画输出属于图片与主图打包，不等于自动完成气泡排版或视频剪辑。

<a id="reference"></a>
## 角色参考与预设库

**入口：参考预设。**

- 管理精准参考与氛围迁移配置，支持分组、导入、导出与离线复用已保存预设。
- 在线目录按游戏、分类、角色形态组织参考图，支持跨语言搜索与五语言显示。
- 可逐项下载或按游戏整系列下载；下载前查看数量和总大小，下载中查看聚合进度。
- 支持双击预览，在生成前选用合适的参考及对应模型参数。

目录获取与已有文件的本地复用是两件事：联网用于下载素材，已保存预设可以离线管理；实际 NovelAI 生成仍然需要联网。

<a id="prompt"></a>
## 提示词与画风

| 工具 | 用途 | 连接要求 |
| --- | --- | --- |
| Tag 自动补全 | 输入英文标签并选取候选，失败时使用本地高频词库 | 在线候选与本地词库分开工作 |
| 灵感胶囊 | 按分类查找中文概念，支持复合查询并插入对应标签 | 本地词库可先使用 |
| 标签权重与通配符 | 用 − / ＋ 微调权重；以 `{red|blue|green} hair` 进行本地随机展开 | 本地提示词处理 |
| 中文翻译 | 将中文提示词翻译成英文 | 谷歌翻译或自行配置百度翻译 API |
| AI 图片反推 | 用视觉模型分析图片并整理提示词 | 另外配置视觉模型 API |
| 提示词转换 | 用文本模型把描述整理成图像提示词 | 另外配置文本模型 API |
| JSON 预设 | 导入、重命名、删除反推 / 转换相关提示词预设 | 预设本地管理，执行时使用相应 API |
| Tag / MCP | 扩展标签检索；支持 HTTP 与 MCP Streamable HTTP / SSE / stdio | 自行配置对应服务 |
| 所长 NovelAI 个人法典 | 离线查找章节与分类、复制提示词、手动更新 | 内置资料可离线查阅 |

### 画风实验室与画师工具

工具区包含目标画风反推、随机画师组合及画师权重相关工具。可以比较 A / B 风格、重试、继续变异，按实际生成模型分类收藏，减少跨模型误用画风结果。

- 随机画师流程使用独立生成参数，可同步生成页或恢复默认值，支持尺寸预设与自定义宽高。
- **Windows 桌面端**额外提供本地相似度模型参与的目标画风迭代。
- 「输入画师串抽卡」保留输入 Tag，在自定义范围内重抽画师权重，批量生成并收藏；可用性以当前平台入口为准。
- 权重修复工具在当前界面显示为「V4.5 画师串修复器」；内部文件名不代表面向用户的模型名称。

<a id="reuse"></a>
## 素材与原数据复用

**入口：原数据、在线画廊。**

### 原数据

本地读取 PNG / JPG / WebP 中保留的 NovelAI、SD WebUI / Forge、ComfyUI 元数据。逐项查看或复制提示词、尺寸、Steps、CFG、采样器、Seed 等，将兼容参数应用到生成页。

SD 模型、VAE、LoRA 和 ComfyUI 工作流用于展示，不会被误套成 NovelAI 模型。原图未保留元数据时，不会凭空恢复精确参数；AI 反推是另一项需要视觉模型的能力。

### 在线画廊

支持作品、作者、标签、模型、ID 和提示词搜索，以及最新作品、排行、时间筛选和分页。支持多图作品、单图与整组下载、原比例预览。

参数应用支持逐项勾选、全选和清空，避免把不需要的字段整套覆盖到当前创作。预览图片有本地缓存，可在设置中查看和清理。画廊请求不携带 NovelAI Token，但访问的仍是第三方在线服务。

<a id="manage"></a>
## 记录、文件与个人设置

- 历史按日期和分组筛选；新建、重命名、删除分组，给图片分组并 ZIP 导出。
- 复用参数、固定 Seed 做变体，继续送入图生图、重绘或后期。
- 生成前填写文件名前缀；历史图片可单独重命名并同步更新本地文件名。
- 浅色 / 深色外观、语言、存储和网络设置集中管理；桌面工作台可调整分栏。
- GitHub / Gitee 下载源可切换；默认 GitHub，备用源用于下载失败时的回退。
