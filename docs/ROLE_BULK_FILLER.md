# 角色提示：批量填充

基于 Yuemil 提出的 PR #93。入口：生成 → 角色提示 → 批量填充。经典版和新版共用角色数据；界面使用当前主题，无需安装插件。

- **从零生成**：填写画面要求，复制 AI 生成指令交给你选择的 AI；把结果粘贴回来或导入 UTF-8 JSON/TXT，在预览中检查角色数、正面词及负面词，再点「填充角色」。复制不会发送内容，也不会扣费。
- **修改现有角色**：点「读取当前角色」，直接编辑草稿，或填写修改要求后点「复制 AI 修改指令」。将外部 AI 的回复粘贴回草稿。应用按槽位顺序保留原有角色的 ID、位置及启用状态；减少槽位时必须确认。
- **命名保存组合**：展开「角色组合预设」，输入名称并保存当前预览。这里只保存角色名称及整组正负提示词，不保存 AI 指令。预设可重新载入草稿，不会立即覆盖工作台；与现有正面预设共用存储及备份。

## 推荐交换格式
```json
{"characters":[{"name":"摄影师","prompt":"camera, short hair","negativePrompt":"hat"},{"name":"模特","prompt":"holding flowers","negativePrompt":""}]}
```
也接受 JSON 数组、AI 的 JSON 代码块、`【角色1】… / 负面1：…`、`角色1：…` 或以空行分段的纯正面词。角色标号从 1 开始、连续且不重复；不截掉超出模型上限的角色。JSON 中省略负面词时保留同位置原值，写 `"negativePrompt":""` 时明确清空。规范化成 JSON 不会改动引号、权重或字段内换行。

MCP 的 `prepare_character_group` 与 `save_character_group` 使用同一个解析器。预览及保存不会发起生成请求。
