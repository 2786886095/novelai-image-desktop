# 普通文字转换：检查警告与失败边界

2026-11-04，本地修复，保持 2.7.6+197；没有发布或触碰用户数据。

## 已确认与未知

- 用户反馈“中文转换没有通过检查”，目前没有具体输入或错误截图，无法确认那次失败的原因。
- 独立合成复现：V2 解析器拒绝完整 text/txt/无标签代码块包裹的合格结果。手机真实转换链可复现；桌面旧转换链先清理代码块，所以不能把此问题直接归因为桌面报告。
- 有效单元数量、混合比例、句式等检查可能拒绝一个仍可供用户使用的结果。按维护者确认，普通文字转换改为警告而非丢弃结果。

## 本地修改

- V2 只解开完整外层文本代码块，正文不补词、不改场景；真实检查仍执行。
- 普通转换的 V2 审计失败返回原模型正文和“检查未通过，已保留转换结果供手动确认”警告。完整角色双版本分别保留实际字符串，不虚构另一版。
- 旧版模板可解析的 typed envelope、数量/比例/事实诊断也以警告交付；原始内部 JSON 不能冒充提示词。V3 不新增 V2 密度规则，不改变所选版本或用户模板。
- 手机结果旁保留可阅读的警告，并有无障碍 live region；手工编辑、套用其他结果后清掉过期警告。
- API 错误、空响应、截断、明确拒绝、无法提取的响应结构仍失败并保留旧提示词。警告不代表质量合格，不自动发起生图。
- 图片反推、明确的提示词助手修复入口，以及桌面独立漫画分镜转换入口，不扩展为此普通转换策略；保留它们已有检查边界。

## 验证边界

使用合成提示词、虚拟密钥、实际回环 HTTP 服务、状态与组件测试。没有真实供应商请求，没有付费生成，也未做原报告的用户环境端到端复现。详见外部同轮证据记录与 BASELINE / MODIFIED / ROLLBACK 输出。
