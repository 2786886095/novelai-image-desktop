# OpenAI 图像编辑（局部重绘）

重绘页新增“重绘引擎”切换：除 NovelAI 外，可以用 OpenAI Images 的编辑接口（`/images/edits`）按蒙版重绘。它擅长文字、logo、按自然语言指令改局部内容。

## 配置

设置 → API 配置 → **OpenAI 图像编辑**：

| 项 | 说明 |
|---|---|
| 接口地址 | 官方 `https://api.openai.com/v1`，或任意 OpenAI 兼容中转（填到 `/v1` 即可） |
| API 密钥 | 独立保存并加密，不与 NovelAI Token、兼容生图密钥共用 |
| 模型 | 默认 `gpt-image-2.5-sunburst`，可改为服务商支持的任意图像编辑模型 |
| 请求尺寸 | 默认“自动匹配标准尺寸”（1024²、1536×1024、1024×1536）；也可选 `auto` 或自定义 `WIDTHxHEIGHT` |

这里的配置**不会**切换软件的生图服务。

## 使用

1. 重绘页 → 重绘引擎选 **OpenAI 图像编辑**。
2. 照常涂抹蒙版（可配合聚焦区域）。
3. 填写“重绘指令”（自然语言），按需选择质量 / 输入保真度（默认不发送，由服务商决定）。
4. 点击 **OpenAI 重绘**。

## 处理细节

- **几何**：图片先补边到请求比例再缩放上传，蒙版同步处理；结果缩放回补边画布后裁回原尺寸，不会拉伸。
- **蒙版**：编辑器蒙版与 NovelAI 重绘同一判定规则，自动转换为 OpenAI 约定（透明 = 重绘区域）。
- **贴回**：模型会整体重绘图片，因此只把蒙版区域（外扩 4px、羽化 6px）贴回原图，蒙版外像素逐字节保持不变。
- **计费**：由 OpenAI / 中转服务按其价格计费，不消耗 Anlas；每次只提交一次请求，失败不自动重试。
- **记录**：结果保存到当前输出目录与分组，历史记录标记为兼容服务结果，并保存不含密钥的请求摘要。
