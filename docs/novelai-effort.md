# NovelAI V5 Effort

Medium / High is independent of Quality Tags and LLM reasoning. Supported: V5 Full and V5 Full inpainting. Requests use `nai-diffusion-5-full-medium` / `nai-diffusion-5-full-medium-inpainting`. Medium fixes 14 steps, Euler Ancestral, built-in heavy UC and zero CFG Rescale. Its unsupported controls are hidden, while stored High settings remain unchanged. Switching effort never edits batch count. The active desktop Pi Agent and mobile Agent accept and preserve effort, including frozen preparation previews.

Quotes take priority when available. Fallback estimates mirror the public frontend V5 multiplier and Medium step factor; remaining Opus image counts are approximate and parameter-dependent, not an account guarantee. The documented ~42% default comparison is not applied as a blanket discount to every resolution, reference fee or provider. Relay charges remain provider-specific.
