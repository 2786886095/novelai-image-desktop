# NovelAI 个人法典数据来源

应用内“NovelAI 个人法典”离线快照来自 `nai4.top` 的下列公开页面：

- 所长常规NovalAI个人法典
- 所长色色NovalAI个人法典(上)
- 所长色色NovalAI个人法典(下)

原页面说明该法典为“无偿免费分享”。应用保留每个条目的来源链接，不改变原提示词内容，仅把页面的“章节 → 条目 → 提示词”结构转换为可离线检索的数据。

内置快照可用 `npm run build:prompt-codex` 重新生成。桌面端与移动端的“手动更新”按钮会读取同一组公开页面，并把结构化结果保存在各自应用数据目录；更新失败时继续使用最后一次成功缓存或内置快照。
