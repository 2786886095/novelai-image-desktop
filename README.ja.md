## 今回の更新

- **Agent ログの認証情報マスキング**：JSON／オブジェクト表示の引用符付きフィールドと、Bearer／Basic などの一般的な認証情報形式に対応。追加した合成回帰テストは実際のエンジンのログ／スナップショット経路を対象とし、実際の認証情報は使用していません。過去の実際の漏えいを立証したものではありません。
- **認証と Anlas 残高の回帰確認**：Anlas 残高は認証応答の必須項目ではありません。追加回帰では、有効なネイティブ認証またはモデル一覧の読み取り専用検証によりアカウントを保存・選択できる既存の動作を確認します。残高未取得は不明のままで、0 や無料枠とは扱いません。HTTP 401／403 は引き続き拒否します。
- **画像生成エージェントの添付**：文字を入力せず TXT だけを添付した場合も、読み取り可能な本文を今回のユーザーメッセージに含めます。システム指示としては扱いません。
- **送信と下書きの状態表示**：添付の読み取り・送信状態と、失敗した下書きを明示的に復元する操作を追加。後続の編集の上書きや二重送信を防ぎ、添付一覧・会話切り替え・狭い画面でのチャット操作を改善しました。
- **画風反復の応答処理**：成功した 2xx 応答でも ZIP、画像内容、要求サイズを検証してから保存します。結果不明のリクエストは自動再送しません。
- **配布パッケージの実行時依存関係**：必要な依存関係を同梱し、ビルド時に依存関係の閉包と展開ファイルの整合性を検査して、依存不足による起動失敗を防ぎます。
- **ローカル ComfyUI ワークスペース**：環境設定を1ページのガイドにまとめ、実際の状態から次の操作を案内します。メインフォルダーから既知の構成の既存 Python を検出し、明示的な起動時に空きポートを確認します。依存関係を無断で導入・更新しません。安全モードは初期状態で無効で、詳細設定から有効化できます。サードパーティーワークフローの実行確認は別途必要です。
- **ワークフローと設定**：MOSS-Image SFT、Anima Base、Krea 2 Turbo の直接プロンプト例と、API JSON・変換を確認できる UI JSON・画像メタデータの取り込みに対応。再起動後に前回のワークフローと各下書きを復元しますが、サービス起動や生成は行いません。内蔵例は名前を付けて別保存、自分のライブラリー記録は上書き保存でき、元ファイルは変更しません。
- **よく使うサイズ**：1024×1024、832×1216、1216×832 を内蔵し、独自サイズも追加できます。ワークフローが実際に持つ幅・高さの入力と許容範囲だけに適用します。
- **タスクと結果**：直近100件をコンパクトなカードと詳細で表示し、1ページ12／24／48／60件から選択可能。保存場所の表示、設定の再利用、全体更新に対応。更新は編集中の値を保持し、再起動や生成を行いません。アプリ再起動後も未完了タスクを自動再送しません。
- **5言語表示とレイアウト**：独立スクロール、重なり順、パラメーター配置を修正。登録済み116種類のノード、434組のノード／入力マッピングを5言語表示します。未知のノード、ファイル名、列挙値、元の ID はそのまま保持し、任意のプラグインや動的ワークフローへの対応を保証しません。
- **検証範囲**：以前の Windows 実機検証で3モデルの生成を確認済みです。最新の画面・ガイド変更は隔離環境での回帰検証であり、新たな GPU／全5 OS の実機検証ではありません。macOS／Linux の推論は未実機検証、Android／iOS にローカル ComfyUI 入口はありません。NovelAI のアカウントや履歴を上書きせず独立保存します。[ガイド（中国語）](./docs/COMFYUI_LOCAL.md)。
- **今回の配布範囲**：ローカル Agent コンポーネントと画風の自動反復は Windows のみを対象とし、macOS／Linux／Android では提供を約束しません。画像生成エージェントを含む残り37機能の4環境での対象範囲は変更しません。今回はメンテナーの明示的な要請により直接公開し、全機能や画像生成の受け入れ検証は追加しません。必須150セルすべての合格を認定するものではなく、Windows の画風自動反復の3つの GPU ネイティブシナリオは未完了です。対象外6セルは not-supported とし合格に数えません。iOS は自分で署名する未署名 IPA の追加配布のみで、通常の iPhone へ直接インストールできません。

## はじめ方

1. リリースページから OS に合うパッケージをダウンロードします。通常利用に Node.js やソースのビルドは不要です。
2. 「設定 → API 設定」でアプリ内の案内に従って Token を入力し、検証または残高更新を行います。
3. 「生成」で利用可能なモデルを選び、プロンプト・画像サイズ・枚数・見積料金を確認して生成します。デスクトップ版の結果は出力フォルダーと履歴に保存されます。

```text
1girl, solo, blue hair, blue eyes, white dress, garden, sunlight, smile
```

最初は既定のパラメーターで試し、生成に成功してから追加サービスを設定してください。表示言語は設定で変更できます。プロンプト、ファイル名、会話内容は翻訳しません。

Windows のローカル酒場 Agent は確認後に検証済み互換コンポーネントを更新し、任意の公式最新版を直接導入しません。ユーザーが追加・変更したプラグインを保持しますが、すべての組み合わせの互換性は保証しません。[更新と復元について（中国語）](./docs/TAVERN_AGENT_UPDATES.md)。

## よくある質問

- **オープンソースなら無料で生成できますか？** いいえ。NovelAI のアカウント、モデル権限、利用枠が必要です。Anlas の実料金はサービス側で決まり、表示額は見積もりです。
- **基本生成にも追加 AI API が必要ですか？** いいえ。まず NovelAI Token のみで利用できます。画像解析・変換・会話モデルの設定と料金は個別です。
- **SD／ComfyUI のメタデータを読むとモデルを実行しますか？** いいえ。解析ツールは互換値の読み取りと再利用だけを行います。別機能のデスクトップ版ローカル ComfyUI では、実環境を用意して接続した後に対応ワークフローを実行できます。NovelAI がそれらのモデルを実行するわけではありません。
- **モバイルは基本生成だけですか？** いいえ。酒場、漫画、参照、ギャラリー、画像解析、メタデータなどもあります。ただし OS により機能は異なります。

[接続と保存のトラブルシューティング（中国語）](./docs/guide/GETTING_STARTED.md#troubleshooting)。

## データと接続

- NovelAI とは API で通信し、ブラウザー自動操作や Cookie 抽出は使いません。デスクトップのリクエストは Electron メインプロセスで処理し、認証情報と設定はローカルに保存します。
- 生成時はプロンプトと必要な参照画像を NovelAI に送信します。追加 AI 機能の入力は設定したサービスに送られ、ギャラリー・参照・タグサービスは各データソースに接続します。
- メタデータ解析はローカル処理で Anlas を消費しません。保存済み参照や辞書のオフライン閲覧は**オフライン生成を意味しません**。
- Issue の投稿前に Token、API Key、個人の会話、機密画像を除去してください。上流ソフトの診断ログは原文で表示される場合があります。
