# 通用视觉映射

这些条目由用户提供的 V4.5 规范与《焚诀》示例提炼。原文中重复、错误拼写、SD 专用权重语法和冲突项已排除。

## 镜头与构图

- 第一人称：`pov`
- 低机位仰视：`from below`
- 高机位俯视：`from above`
- 看向观众：`looking at viewer`
- 全身：`full body`
- 正面：`from front`
- 背面：`from behind`, `facing away`
- 远景：`distant`, `long shot`
- 全景或广角：`wide shot`
- 透视缩短：`foreshortening`
- 倾斜镜头：`dutch angle`
- 牛仔镜头：`cowboy shot`
- 肖像近景：`portrait`, `close-up`

## 背景

- 简单背景：`simple background`
- 白色背景：`white background`
- 虚化背景：`blurry background`
- 无人物场景：`background dataset, no humans`

## 表情

- 坏笑：`evil smile`
- 得意：`smug`
- 半闭眼：`half-closed eyes`
- 闭眼：`closed eyes`
- 张嘴 / 闭嘴：`open mouth` / `closed mouth`
- 嫌弃：`disgust`
- 吐舌：`tongue out`
- 歪头：`head tilt`
- 咧嘴笑：`grin`
- 脸红：`blush`
- 咬牙：`clenched teeth`
- 流泪：`tears`
- 出汗：`sweat`

## 手部与日常动作

- 嘘声：`shushing`
- 手叉腰：`hand on own hip`
- 托腮：`hand on own cheek`
- 比耶：`v sign`
- 整理头发：`adjusting hair`
- 把头发别到耳后：`hair behind ear`
- 双臂抱住自己：`hugging self`
- 手放在大腿上：`hand on own thigh`

## 腿部与姿态

- 抬腿：`leg up`
- 盘腿：`crossed legs`
- 踮脚：`tiptoes`
- 足部特写：`foot focus`
- 站立：`standing`
- 坐着：`sitting`
- 蹲下：`squatting`
- 跪着：`kneeling`
- 弯腰：`bent over`
- 前倾：`leaning forward`
- 侧坐：`yokozuwari`
- 鸭子坐：`wariza`
- 动态姿势：`dynamic pose`

## 颜色与媒介

- 黑白或单色：`monochrome`
- 动画上色：`anime coloring`

## 使用提醒

- 映射只在输入确实包含对应视觉信息时使用。
- `pov`、`from above/below`、`close-up/full body` 等构图词必须先做冲突检查。
- 不要用 `five fingers`、`five toes` 之类正面 Tag 代替解剖质量控制；它们可能反而强化肢体表现。
- 负面提示词应短而针对当前失败，不应复制大段重复、拼写错误的旧式负面词库。
