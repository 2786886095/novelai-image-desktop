# 来源与质量说明

## 来源

- 用户提供的 NovelAI V4.5 / Danbooru 转换规范：核心结构、多人分段、互动锚定、权重和冲突检查。
- 软件内置三套 NovelAI 个人法典：常规法典与两套可选分级法典。
- 用户提供的《焚诀.docx》：镜头、表情、姿态、服装与分级示例。

## 可信度边界

- NovelAI 的接口和模型行为可能变化；资料是实践经验，不应称为官方规范。
- Danbooru Tag 是否存在、是否适用于当前模型，应优先通过本地 Tag 库、MCP 或 Danbooru 数据验证。
- 个人法典的条目用于召回候选表达，不应整段无条件粘贴。
- 《焚诀.docx》含错误拼写、重复负面词、旧式质量词和混用语法；仅保留经过清理的可复用映射。

## 扩展约定

新增条目必须包含：

- 稳定 ID
- 标题
- 分类
- 中英文关键词
- 可注入的简短规则或 Prompt 片段
- 来源
- 是否分级
- 适用模式（转换、反推或两者）

不要把完整小说段落、无关剧情或未经校验的超长 Prompt 直接加入检索索引。
